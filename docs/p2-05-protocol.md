# P2-05 · 수평 목표 도약 기준선

2026-09-12 학습 전 고정. P2-04의 제자리 정밀 도약·안정화가4seed의 개발평가에서각64/64 성공한 뒤, 목표를 전방으로 옮기는 과제로 확장한다. 여전히 평지이며 갭이나 제한된 발판은 구현하지 않았다.

## 명령과 성공 계약

새 task `a1_directed_jump_v5`. reset마다 네 발 목표에 동일한 전방 거리0–15cm를 균등 추출해 더한다. 높이4–6cm와 구동기·물리·66차원 관측·PPO·기존 보상 항은 P2-04와 같다. 목표 좌표는 기존 관측 채널에 들어간다.

유효 비행을 처음 확인한 제어 표본에서 몸체 XY를 저장한다. 초기 보정된 몸체 XY에서반경3cm 밖이면 실패로 종료한다. 이 기준은 env 원점 자체가 아니며, A1의 보정 자세 오프셋을 포함한다. 목표까지 걸어간 뒤 제자리 점프하는 우회를 막기 위한 출발 조건이다.

비행 후 최초 발 접촉의200Hz 표본에서 몸체 XY를 한번 저장한다. 두 표본 사이의 전방 이동량을 실제 관측 비행 이동량으로 보고한다. 제어주기와20ms 비접촉history 때문에 이륙보다 늦은 지점부터 재므로 전체 이륙-착지 거리와 같지 않은 보수적 측정이다.

성공은 P2-04의 정밀 첫 접촉·연속 안정화 조건에 출발 영역과 최소 비행 이동 조건을 모두 더한다. 비영점 목표는전방 이동≥max(0,목표거리−3cm)를 요구한다. 0cm 목표에는 양의 이동을 강제하지 않는다. 5cm 평가 목표는최소2cm,10cm는7cm,15cm는12cm이다. 미접촉 상태의 이동 기록은-1과별도유효성flag로표시하며 실제 후진거리로해석하지않는다. 출발기준을벗어난비행외에는기존실패/4초제한을유지한다.

새 성공 조건만 추가하고 추가 이동 보상은 두지 않는 기준선이다. 기존 목표 위치 보상과 첫 착지 보상으로 새로운 명령을 학습할 수 있는지 확인한다. 기존 제자리 성공률과 동일 과제로 직접 비교하지 않는다.

## 예산·평가

신규 seed0/1/2/3 각각1024환경×24step×1600updates, 총157,286,400 환경step을 처음부터 학습한다. 마지막 checkpoint를0/5/10/15cm 각각16개로평가한다. 동일16개 높이 명령을각거리에배치해총64개이며거리별성공·출발조건·실비행이동·첫접촉·안정화를보고한다.0cm를기존능력유지확인으로사용하되16개명령의새개발평가라는범위를명시한다.

고유scenario ID·동일거리분포·높이paired·prefix재현성,지상보행우회·이동없음·후진·0cm허용조건을검사한다. 실제시뮬레이터합성상태주입은관측과판정연결검사이며정책성능으로보고하지않는다. 별도64환경×2updates와자동평가·MP4·200Hz·hash/자원회수를본예산에서제외하고먼저검증한다. 평가에서최초접촉원본과온라인값을대조하며,새이동latch도rootXY원본과확인한다. 자동champion승격은없다.

구현 검증 결과: 단위32개 통과. 실제 합성 검사에서 관측66차원·명령 범위·정지 거부·출발 영역 밖 상승 비행 거부·0cm 및15cm의 합성 착지 성공 연결을 확인했다(`artifacts/p2-05-directed-state-check.log`). 별도2update 학습과 자동 평가, 출발/거리 요약을 분리한 최신 코드의추가평가`p2-05-directed-validation-v2`, 총3run의hash/UUID/회수감사를통과했다. 본 실험 예산에서 제외한다. 짧은 정책에는 유효 비행이 없어 양성 원본 이동 대조는 본 평가에서 추가 확인한다. 출발 충족과 순수 거리 충족은 별도 지표이고, 전체 travel_requirement_met은두조건의결합이다.
