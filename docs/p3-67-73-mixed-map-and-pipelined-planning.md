2026-09-13. 모든 결과는 시뮬레이션 개발 실험이다. 동일 맵의 64개 복제 환경을 64개 독립 지형/학습 seed로 해석하지 않는다.

- **P3-68**: 35cm 전체 난이도, bridge/direct 모두 추가 1200 updates 후 0/64. 점진 난이도의 최종 단계 성공은 입증되지 않았다. 실패와 원본 영상은 보존했다.
- **P3-69**: 기존 P363 모델의 새 혼합 맵 평가. 25%와 100% 모두 0/64; 평균 이동 구간 6.890625/3.0. 개발 맵의 폭·회전·경사를 더 어렵게 하면 기존 정책이 그대로 일반화하지 않는다.
- **P3-71**: 처음 네 착지를 물리 검증한 뒤, 미래 비행 상태를 캐시하여 실행과 후속 네 착지 계산을 겹쳤다. 초기 계산 2.307초; 첫 후속 계산 1.664초, 활성화 시 root 오차 0.90mm로 후보7 적용. 두 번째 계산 1.817초였으나 관절 상태 오차로 기각. 24구간 완주, 주행 12.155초, 엄격한 주행 도약 15회. 이후에는 이전에 승인한 목표를 유지했다. 전 구간 반복 재계획 성공은 아니다.
- P371 제어 연산 p95 20.23ms, 20ms 초과 45회. 하드 실시간 완료 조건 미충족.
- P371 명목 고정 목표 대조 실행도 완주. 별도로 **동일한 초기 후보7을 고정한 대조**는 24구간에 도달했지만 몸체 접촉으로 실패했다. 각각 한 개발 episode이며 정책 변경의 통계적 우월성을 주장하지 않는다. 다른 실행 파일의 시간 수치를 직접 속도 개선으로 해석하지 않는다.

## 새 지도와 학습

`mixed_discrete_v1`: 25개 공유 발판, 24개 실제 분리 구간. 처음 세 이동은 P363 접근을 보존한다. 이후 발판 폭·롤/피치·높이·방향·간격을 함께 변화시킨다. 전체 난이도 최소 폭 50cm, 최대 설계 갭 60cm, 최고 표면 중심 48cm. 25%, 50%, 75%, 100% 명시적 geometry를 생성하며 실행 가능성은 별도 검증한다.

[지도 그림과 JSON](../result/scenarios/mixed-discrete-difficulty-designs/README.md).

P370: 같은 P363 부모에서 1024환경 × 1200 updates 두 조건. clean reset / 50%의 초기 XY ±2.5cm·yaw ±0.04rad 변동. 높이·관절·속도는 바꾸지 않는다. 평가에서는 변동을 끄고 초기 조건을 고정한다. native와 새 geometry seed2를 평가한다. Native 완료 결과는 control 52/64, jitter 39/64. 평균 이동 구간은 21.9375/23.34375. 두 조건의 고정 env0 모두 성공했고 주행 11.815/12.075초, 엄격한 도약 9/11회다. seed2 결과는 해당 evaluation artifact를 확인한다.

P372: P370의 **native 개발 성공 수, 그 다음 평균 이동 구간**으로 부모를 고른다. seed2 평가로 부모를 고르지 않는다. 같은 부모에서 25% 계속 학습 / 50% 어려운 맵 학습 각각 1200 updates. 두 모델 모두 25%/50% 평가로 개선과 회귀를 확인한다. 이 단계가 더 어려운 지도 통과를 보장하지는 않는다.

## 계획·기록 계약

`pipelined_planner_probe.py`: 초기 물리 계획은 주행 전 실행한다. 이후 캐시한 미래 상태에서 다음 4개 표면의 발 목표 후보를 검증하고 예정 시점에 전달한다. 실제 root·회전·관절·속도·접촉·계획 hash가 맞을 때만 적용한다. 거절하면 해당 파이프라인을 멈추고 승인된 목표를 유지한다. 실제 상태를 다시 받아 파이프라인을 복구하는 기능은 아직 없다.

캐시 snapshot은 `planner_only=True`이며 lean planner에만 복구할 수 있다. 실제 비행 force 조건을 확인하며, 업데이트하지 않은 reward/flight counter를 만들어 넣지 않는다. 숨겨진 PhysX solver 상태를 복원하거나 PPO 재학습 reset으로 쓰는 기능이 아니다.

P373은 동일 계약에서 매 스텝 CPU 복사 대신 제한된 GPU trace buffer를 사용한다. 종료 후 일괄 변환하며 기존 root/joint/target/contact 재생 필드를 보존한다. 실제 비교가 끝나기 전 지연 감소를 주장하지 않는다. 동일 초기 계획을 가진 대조 실행과 각 상태 재생 MP4를 만든다.

## 아직 남은 최종 목표

혼합 난이도 완주·새 지도 일반화, 전 구간 반복 온라인 계획 및 예측 불일치 후 재계획, deadline 안정성, 표면 순서 자체의 경로 선택이 남아 있다. 지금 Planner는 주어진 표면 순서에서 발 목표 위치 후보를 선택한다. 다중 학습 seed와 잠근 최종 시험군의 연구 결과는 아직 아니다.
