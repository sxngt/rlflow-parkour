# P2-15 유한 지지면 학습 기준선

상태: 구현 smoke 검증 단계. 주요 학습 결과 확인 전에 고정한 비교다.

P2-14에서는 작은 발별 지지면에서 모든 기존 정책이 유효 도약 전에 실패했다. 넓은 발판은 일부 성공했지만 평지와 다른 행동을 보였다. 재질 명시 비교에서는 episode 결과가 동일했다. 이번에는 유한 지형을 처음부터 학습에 포함했을 때 넓은 발판에서의 실행을 배울 수 있는지 확인한다. 작은 발판·갭까지 해결했다고 주장하지 않는다.

- 조건: 무한 평지 / 1.4×1.2m 단일 발판. 상면 z=0, 발판 두께10cm, 아래 포획 평면 z=-0.5m. 동일한 명시적 마찰0.5, 반발0, average combine.
- 두 조건 모두 같은 저장된 평지 calibration을 초기 상태로 사용한다. root/joint/foot 순서, 원본 hash 및 geometry를 terrain_contract에 포함한다. 지형별 재교정으로 시작 자세가 달라지지 않게 한다.
- 각 조건 seed0–3, fresh PPO. checkpoint 가중치·optimizer를 다른 run에서 가져오지 않는다. 기존 P2-11과 같은 관측66차원·행동·보상·알고리즘·네트워크·목표 거리0–15cm·launch radius curriculum을 사용한다.
- 각 run 1024환경×24step×1600update = 39,321,600 환경step. 총8개 run = 314,572,800step. 조건별 예산을 동일하게 유지하며 step 외에 wall-clock/GPU시간도 보고한다.
- 처음 네 GPU에 평지seed0/1과 발판seed0/1을 배치하고, 종료 후 두 조건seed2/3을 배치한다. 설정을 확인한 단기 smoke는 연구 예산과 결과에서 제외한다.
- 추가 지도/발판 경계 관측은 이번 비교에 넣지 않는다. 각 정책이 학습하는 지형은 고정이다. 따라서 여러 지지 영역에 일반화하는 지도 조건부 Tracker를 검증하는 실험은 아니다. 후속 좁은 지지면·갭 커리큘럼의 기준선이다.

모든 최종 정책을 평지와 발판 양쪽에서 평가한다. 각 조건 같은64개 개발 episode(거리0/5/10/15cm×16높이 명령)를 사용한다. 기존 P2-14의15cm전용64episode와 표본 구성을 혼동하지 않는다. 성공·유효비행·최초접촉·안정화·실패원인·지지면 이탈을 seed별로 보고한다. 원래 성공 조건과 발판 내부 접촉 진단을 분리한다.

checkpoint 계약에 terrain_contract를 포함하여 다른 지형의 checkpoint를 정상 resume로 취급하지 않는다. 교차 지형 평가는 원래 모델 계약으로 복원하고 명시적인 평가 override를 기록한다. 주요 run 전에 짧은 학습·checkpoint 재개·동일/교차 평가 및 200Hz 진단·영상 경로를 검사한다.

각 최종 평가 영상은 64개 활성화와 camera-side4를 사용하고 result에 조건·seed·학습횟수를 명시한다. step:p2-15-terrain-training 태그로 검색한다. 최종 성능이 나쁠 때 예산을 임의 연장하지 않고 준비 단계의 지지와 관측 부족을 분석하여 다음 실험을 따로 정의한다.

구현 검사 완료: 64환경3update 및 checkpoint3→4 재개, 동일발판/평지교차 평가4episode,200Hz진단·영상·result저장,4artifact감사통과. 교차평가의거리0/5/10/15cm와scenario목록동일확인. unit tests42통과. 이smoke는학습성과비교에서제외한다.
