# P2-16 중간 체크포인트 진단

최종 결과 확인 후 추가하는 개발 진단이다. 추가 평가 결과를 보기 전에 다음 범위를 고정한다.

각 seed0–3의 checkpoint800 및1200을 평가한다. 최종1600 결과는 기존 평가를 재사용한다. 추가학습0step, 추가평가8개×64episode. 같은 저장된 발판·calibration·관측·정책 normalization을 유지하며 각 checkpoint의 원래 hash를 검증한다.

평가 조건은 모두 최종 조건인 출발반경3cm 및 거리0/5/10/15cm×16높이 명령이다.800checkpoint가 실제 학습했던0–10cm/6cm 출발반경과 다르다는 점을 명시한다. 이는 고정된 목표 조건의 능력 변화이며, 거리 확장이나 반경 축소 각각의 인과효과를 분리하는 실험이 아니다.

주요 비교는 seed별 성공·유효비행·이동거리·최초접촉·안정화와 거리별 성능이다. 중간 모델이 최종보다 좋으면 퇴화 후보로 기록하되 개발 모델 선택임을 밝힌다. 모든64episode는 동일 목록으로 수집하고200Hz 진단/64개 근접구도 영상/result 저장을 유지한다. phase:P2,step:p2-16-distance-curriculum,purpose:checkpoint-diagnosis,checkpoint:800 또는1200 태그를 사용한다.

실패한 평가만 새 attempt로 재실행할 수 있으며 추가 checkpoint 선택이나 학습 연장은 별도 실험으로 둔다.
