# P2-10 · 3cm 출발 조건 직접 학습

P2-09는 6cm 조건에서15cm 도약을 네 seed 모두 해결했으나3cm 재평가에서는 모두 출발 범위 위반으로 실패했다. 평가에만 엄격한 조건을 주었기 때문인지, 같은 조건으로 학습해도 어려운지 분리한다.

P2-09에서 jump.launch_radius_m만0.06→0.03으로 바꾼다(태그 제외). 보상·0–15cm 학습 분포·PPO·성공 기준을 모두 유지한다. 기존 P2-05의3cm 학습에는 비행거리 보상이 없었으므로 같은 실험의 반복이 아니다.

새 정책 seed0–3, checkpoint 전이 없음. 각1024환경×24step×1600updates=39,321,600step, 합157,286,400step. GPU당 독립 실행1개, worker3600초. 중간 결과로 예산이나 설정을 변경하지 않는다.

최종 고정0/5/10/15cm 각16개 평가,200Hz 진단,16로봇 MP4. P2-09의3cm 재평가와 같은 조건으로 seed별 비교한다. 15cm 개선뿐 아니라0/5/10cm 회귀와 출발·비행거리·첫 접촉·안정화 실패를 분리한다. trace episode3 사전 선택. 평가영상은 result에 보존하고 phase:P2 및 step:p2-10-strict-training으로 검색한다.

실패하면 똑같은 실행을 무한 연장하지 않고 출발 조건 커리큘럼/명시적 전이를 검토한다. 비행 확인 시점은 정확한 이륙 순간이 아니므로 추후 발판 지지 영역과 물리적 출발 feasibility는 별도로 검증한다. 현재 평지 조건이며 실제 갭·Planner·실기 검증이 아니다.
