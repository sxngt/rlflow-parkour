# P1 · Step 02 — 3발 지지·최종 안정화 파일럿 프로토콜

2026-09-10, 학습 결과를 보기 전에 고정한다. 기존 v2 정책·결과는 보존한다. v3는 다른 성공 계약이므로 v2의 64/64와 성공률을 직접 우열 비교하지 않는다.

## 공통 과제

A1, flat-only, 1024환경, PPO, 69관측, 관절 위치 offset ±0.5rad, 200Hz physics / 50Hz control. 초기 자세·목표 분포·FR→RL→FL→RR 순서는 v2와 동일하다. 발 들기와 착지 이벤트에는 다른 발 3개 지지가 필요하다. 이는 이벤트 시점 조건이며 에피소드 전체의 지속적 3발 지지를 보장하지 않는다.

네 발 이동 후 별도 최종 안정화 stage 4에 들어간다. 4발 모두 2.5cm 이내 목표 접촉, |몸체 수직 속도|≤0.1m/s, 몸체 각속도 norm≤0.5rad/s, 보정된 초기 높이 대비 오차≤4cm를 0.2초 연속 유지해야 성공이다. 안정화 stage도 69관측의 진행 값으로 표시한다. 종료 실패 조건·12초 시간제한은 유지한다.

## 비교와 예산

- A: 위 계약, 추가 수직 속도 벌점 계수 0.
- B: A와 같고 dense reward에 −4·v_z²만 추가(기존과 같이 control dt를 곱함).
- 각 조건 seed 0,1을 처음부터 800updates 학습한다. checkpoint transfer는 하지 않는다.
- 각 run 1024 × 24 × 800 = 19,660,800 환경 steps. 전체 4 run = 78,643,200 steps.
- GPU 0/1에 A seed 0/1, GPU 2/3에 B seed 0/1. 각 run 독립 PPO이며 4 GPU 분산 학습이 아니다.
- 이 실험은 2개 seed의 탐색적 파일럿이다. 접촉 정보/이력의 연구 질문을 검증하거나 일반적 수렴을 주장하지 않는다.
- 짧은 별도 구현 검증과 zero 대조군은 학습 비교 예산에서 제외해 명시한다. 결과를 본 뒤 학습 예산/보상 가중치를 바꾸지 않는다.

## 평가·판단

각 800-update 모델을 같은 64개 개발 시나리오에서 deterministic inference로 평가한다. 완주율·완료 접촉 수와 최종 안정화 실패를 우선하고, 200Hz motion diagnostics로 무접촉 구간·몸체 수직 운동·접촉력·지지 발 이동을 비교한다. 기존과 동일하게 첫 episode만 집계하며 reset 후 데이터는 제외한다.

몸체 움직임 감소만으로 개선이라고 하지 않는다. 접촉 진행/완주가 퇴화해 가만히 서는 정책이 됐다면 기각 근거로 보고한다. 실패·시간초과와 조건 간 seed 편차도 모두 보존한다. 개선 여부가 불명확하면 추가 연구의 근거로 삼으며 자동 champion 승격은 하지 않는다.

각 최종 평가는 16대 병렬 MP4·diagnostics.json·motion-trace.npz를 보존하고 result/와 웹에서 P1 + step:02-foothold-baseline + purpose:comparison + condition 태그로 구분한다.
