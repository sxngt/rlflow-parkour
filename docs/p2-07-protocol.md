# P2-07 · 출발 영역 제약 진단

2026-09-12, 학습 시작 전 고정.

P2-06은 제자리/0–5cm 두 조건×두 seed 모두 유효 비행0/64였다. 기존 P2-04 성공 정책의 비행 확인 위치는 보정 출발점에서4.18–5.06cm 떨어져 있었다. 새로운3cm 출발 제한이 학습에 미치는 영향을 분리한다.

## 변경과 예산

P2-06의 각 설정에서 jump.launch_radius_m만0.03→0.06으로 바꾼다. 태그 외 보상·관측·지형·나머지 종료 기준은 같다. 6cm는 기존 성공 정책의 관측 범위를 포함하는 진단값이다. 실제 발판의 접촉 영역에서 유도한 값은 아니다.

- zero, seed0/1: 제자리 학습, GPU0/1.
- short, seed0/1: 0–5cm 학습, GPU2/3.
- 각1024환경×24step×1600updates, 총157,286,400 신규step.
- 신규 정책 학습, 전이 없음. worker 제한3600초, 자동 평가·MP4·200Hz 기록.
- 같은0/5/10/15cm×16개 개발평가. 학습 범위 밖 거리는 전이 진단.
- 그림 episode1(5cm)을 미리 선택한다. 종료 전 설정 변경 없음.

## 해석과 보고

일차 질문은 유효 비행·정밀 첫 접촉·안정화가 회복되는가다. 성공률은6cm 계약의 수치로 명시하며 P2-06의3cm 성공률과 동일 기준 개선이라고 부르지 않는다.

각 episode의 launch_root_xy와 보정 출발점 사이 거리를 원본 기록과 대조한다.6cm 계약 성공 중3cm 이내인 수를 별도 사후 집계한다. 이는6cm 조건에서 실행된 궤적의 부분집합 평가이며3cm 종료 조건으로 재실행한 결과를 대체하지 않는다. 기존3cm 과제 달성을 주장하려면 그 조건으로 별도 평가해야 한다.

3cm 평가 원본과 결과는 그대로 보존한다. 모델 자동 승격 없음. 기준 완화 자체를 연구 성능으로 제시하지 않는다.6cm에서 회복되면 수평 이동의 학습 및 실제 출발·착지 지지면 geometry를 다음 단계로 검토한다. 회복되지 않으면 비행 전 반복 보상과 높이 진행 유인을 별도로 조사한다. 실패를 이유로 동일 조건의 학습 예산을 무한 연장하지 않는다.
