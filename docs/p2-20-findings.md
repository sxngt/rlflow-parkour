# P2-20 판단과 다음 실험

4개 학습이 각각 1,600 update, 39,321,600 환경 step으로 완료됐다. 학습 4개와 최종 평가 4개의 artifact 감사가 모두 통과했다. 체크포인트와 영상 hash, GPU 자원 해제, 지형 계보를 확인했다. `result/`의 최종 영상 4개는 64개 렌더링 환경과 camera framing_side=4이며 seed0의 0.8초 프레임도 확인했다.

| 학습 seed | P2-18 성공 /64 | P2-20 성공 /64 | P2-20 유효 비행 | 정밀 최초 접촉 | 안정화 |
|---|---:|---:|---:|---:|---:|
| 0 | 0 | 48 | 64 | 64 | 64 |
| 1 | 0 | 48 | 64 | 64 | 64 |
| 2 | 0 | 24 | 64 | 64 | 40 |
| 3 | 33 | 22 | 64 | 64 | 45 |

제한된 탐색 일정에서 네 seed 모두 도약과 정밀 최초 접촉을 습득했다. 성공 수의 seed 평균은 8.25에서 35.5로 증가했으나 seed3은 감소했다. 네 seed의 개발군 결과이며 통계적 유의성이나 보편적 우월성을 주장하지 않는다. 기존 결과를 재사용한 대조다.

seed0/1은 0·5·10cm에서 각각 16/16 성공했다. seed2는 0cm 16/16, 5cm 8/16, seed3은 0cm 16/16, 5cm 6/16이다. 15cm에서는 모든 seed가 0/16이다. 최초 접촉과 안정화는 15cm에서 모두 충족했지만 비행 이동 거리 기준에 미달했다. 15cm 명령에서 실제 기록된 평균 비행 거리는 seed별 11.26·8.13·9.47·6.12cm로 최소 기준 12cm보다 작다. 판정 허용치를 늘려 해결하지 않는다.

모든 성공 사례의 최초 발 접촉은 발판 내부 투영·높이 검사도 통과했다. 이는 실제 접촉 쌍이나 지속 지지 검증을 대신하지 않는다. 좁은 발판 또는 실제 갭 통과가 입증된 것은 아니다.

훈련 단계별 통계는 `p2-20-training-stages.md/json`, 재생성 명령은 `python3 scripts/p2_20_training_report.py`다. 최초 훈련 성공 update는 803·803·1120·804였다. 비교군 P2-18은 전 학습 구간에서 성공이 없었다. 목표 분포와 출발 반경도 전환되므로 경계 전후만으로 cap의 인과 효과를 분리하지 않는다.

현재 P2-20은 후속 진단의 기준 후보로 보존한다. 모든 seed의 안정적인 15cm 도약이나 연속 파쿠르 완료 조건을 충족하지 않으므로 champion 승격은 하지 않는다.

다음은 동일한 고정 개발군에서 checkpoint800/1200을 평가해 도약 거리와 안정화가 학습 중 획득된 뒤 상실됐는지, 끝까지 미획득인지 분리한다. P2-16과 같은 시간축 진단이지만 새 bounded 정책의 checkpoint buffer와 effective std 복원을 확인한다. 최종 평가를 보고 선택한 사후 진단임을 명시하고, 추가 학습이나 유리한 checkpoint를 최종 결과로 대체하지 않는다. 이후에 거리 학습 분포 또는 보상 변경을 하나씩 사전 규약으로 비교한다.

코드 확인: `first_travel_reward`는 episode 누적 보상이 아니라 현재 제어 step의 지급액이다. 최종 episode 행의 0을 보상이 한 번도 지급되지 않았다는 근거로 사용하지 않는다.
