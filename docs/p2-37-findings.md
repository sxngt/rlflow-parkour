# P2-37 결과: 목표 유지와 지지면 이전의 실패를 구분

새 deck 평가8개와 재사용 continuous 평가8개, 거리별32짝을 검증했다. checkpoint·관측/학습 설정(연구 태그 제외)·평가 행동·보정·목표/초기조건 시나리오가 같고 지지면 mode/layout만 다름을 확인했다. 원본200Hz 판정,16개 영상과 이벤트 보관 hash도 통과했다. [비교표](p2-37-comparison.md), [거리별 실패 판정 데이터](p2-37-comparison.json)를 남긴다.

P2-36 혼합 seed0·2는 deck의0/5/10/15cm를 모두16/16 성공했다. 같은 목표의 continuous에서는 seed0이0/16/16/16, seed2는0/0/0/0이었다. 적어도 이 두 모델의 기존 회귀 결과를 모든 거리 목표의 실행 능력 소실로만 설명할 수 없다. 학습에 사용한 넓은 지지면에 대한 성능과 좁은 발별 지지면으로의 이전을 분리해야 한다.

seed1 혼합은 deck에서도16/14/16/2로 완전하지 않으며, continuous에서는16/16/0/0이다. seed3도deck16/0/8/16,continuous16/0/0/0으로 목표별 실패가 남았다. 따라서 지형 혼합만으로 모든 seed가 해결될 것이라고 주장하지 않는다.

seed2 continuous의 모든 거리에서 출발 영역·이동거리·첫 접촉·최종 발 위치 기준이 모두 미충족이었다. 대부분 유효 비행도 없었다. 이 지표들은 실패 단계의 관측이며, 단일 원인이나 정확한 물리적 미끄러짐의 증거는 아니다. 정적 보정이 같아도 운동 중 지지면 경계와 충돌 반응은 달라질 수 있다.

신규 학습0step, 신규 완료512episode, 재사용512episode다. 최초4시도는 CLI가deck 거리 override를 거부해 시뮬레이터 실행 전에 종료됐다. 기존 실패 로그와 명세를 보존하고 경계 검사 테스트를 추가한 뒤 별도retry1 시도8개로 완료했다. 거부된시도를성능평가실패episode로집계하지않았다.

다음 구현의 우선 과제는 연속 도약용 deck 환경과 단일 목표 유지용 continuous 환경을 같은 현재 정책 rollout에 넣는 것이다. 목표 혼합 비율·총step·부모를 고정한 대조가 필요하다. 환경별 다른 충돌 geometry가 실제로 생성되고 다른 환경과 충돌하지 않는지, 같은 보정·마찰이 유지되는지 먼저 검증해야 한다. 아직 해당 혼합 지형 환경을 구현하거나 본학습하지 않았다. P2-36 모델 승격 보류를 유지한다.
