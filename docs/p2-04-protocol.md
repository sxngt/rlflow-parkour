# P2-04 · 정밀 착지 이후 지지 유지

2026-09-12 본 학습 전 고정. P2-03은 모든 seed에서 첫 착지 반경을 충족했지만, 이후 네 발 지지 유지가 부족했고 일부 seed에서 재비행과 수직 진동이 관측됐다.

새 task `a1_flat_jump_supported_v4`는 P2-03의 엄격 성공 계약, 첫 접촉 기록, 관측66차원, 구동기, 센서, PPO, 명령 분포와 기존 보상을 유지한다. 최초 착지가 감지된 뒤에만 다음 비용을 추가한다.

`dt * (2.0 * vz² + 1.0 * (1 - contact_count/4))`

접촉 수는 기존5N onset/2N release의 hysteresis 상태를 사용한다. 비행 전과 최초 착지 전에는 추가 비용0이다. 수직 양방향 속도를 같은 크기로 취급하며 정지·네 발 지지에서는0이다. 첫 착지 위치·힘 임계값·0.2초 hold·최종 높이와 속도 허용 범위는 완화하지 않는다. 두 항을 결합하므로 개별 기여를 분리해 주장하지 않는다.

신규 seed0/1/2/3 각각1024환경×24step×1600updates, 총157,286,400 신규 환경step을 처음부터 학습한다. 대조군은 동일 예산의 P2-03 원본4seed이며, 이번 비교는 엄격 성공 계약이 동일하다. 마지막 checkpoint를 같은64개 개발 명령으로 deterministic 평가한다. 성공률, 첫 접촉 반경, 기존 안정화 달성, 발별 오차, 접촉 history 위반, 착지 후 수직속도와 지지 비율을 함께 보고한다. 새 모델을 자동 승격하지 않는다.

순수 함수에서 착지 전0·완전 지지 정지0·접촉 결손·수직 속도 부호 대칭·기존 가중치0을 검사한다. 기존 합성 정밀 착지 판정 검사와 별도64환경×2update 학습/평가/MP4/200Hz/자원 회수 감사를 통과한 뒤 본 학습을 실행한다. 구현 확인 비용은 본 비교에서 제외한다. 첫 접촉 온라인 기록과 사후 원본 계산 일치를 확인하며, 미접촉-1을0오차로 해석하지 않는다.
