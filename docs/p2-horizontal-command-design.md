# 수평 목표 도약의 준비 계약

2026-09-12 설계 초안. P2-04의 최종 평가 전이며, 이 문서는 새 시뮬레이터나 학습 실행 완료를 뜻하지 않는다.

정밀한 제자리 착지만 반복하지 않고 수평 목표와 이후 제한 착지면으로 확장한다. 첫 후보는 평지에서 네 발의 목표를 함께 전방으로 옮기는 과제다. 개발 평가는0/5/10/15cm 각각16개, 같은16개 높이 명령을 각 거리에 재사용하는64개 조합으로 준비한다. 0cm는 제자리 능력 유지 확인용이다. `directed_jump_scenarios`는 이 명령 manifest만 생성하며 기존 평가 생성기와 분리돼 있다.

## 성공을 오해하지 않기 위한 조건

단순히 목표를 옮기면 로봇이 목표까지 걸어간 뒤 제자리에서 뛰어도 성공할 수 있다. 이를 수평 도약으로 보고하지 않도록 다음을 별도로 구현·검증해야 한다.

- 고정된 초기 출발 영역에서 도약해야 한다. 최초 유효 비행 때의 몸체 XY를 기록하고, 출발 영역을 벗어난 뒤 도약한 경우를 구분한다. 출발 여유의 제안값은3cm이며 본 프로토콜에서 확정한다.
- 유효 비행 확인 시점과 첫 착지 시점의 몸체 XY를 각각 저장한다. 실제 비행 중 전방 이동량을 보고한다. 위치 목표 오차만으로 수평 이동을 증명하지 않는다.
- 목표가5cm인데 발 목표 반경도5cm이면 거의 이동하지 않아도 반경 조건만 만족할 수 있다. 비영점 명령에는 별도의 최소 비행 이동량 조건이 필요하다. 제안은 `max(0,명령거리-3cm)`이며, 제어 주기의 비행 감지 지연을 포함한 보수적 측정임을 명시한다.
- 0cm 명령에 양의 전방 이동을 강제하지 않는다. 기하학적 범위 밖 reset·지상 보행 우회·비행 없는 발 옮기기·목표 방향 반전의 합성 사례를 검사한다.
- 기존 비행/첫 접촉/안정화 조건은 보존한다. 바뀐 성공 계약을 제자리 과제 성공률과 같은 의미로 비교하지 않는다.

평지에서 검증한 뒤 실제 발판 geometry와 갭으로 확장한다. 빨간 목표 표시만으로 제한된 착지면을 구현했다고 주장하지 않는다. 이 설계는 아직 학습 전 수치 확정이나 물리 검증을 대신하지 않는다.
