# P2-28 실제 분리 지지면 전이 결과

P2-27 네정책을동결해continuous/split에서동일15cm목표×64높이명령으로평가했다. 추가학습0step,8평가512episode. 모든artifact감사와동일scenario/checkpoint/calibration대조,200Hz최초접촉오차대조가통과했다. 영상8개hash/64env/camera4/태그와seed2 split preview를확인했다. GPU모두해제/저장532GB.

| seed | continuous 성공 | split 성공 | split 유효비행 | split 안정화 | split 거리충족 |
|---|---:|---:|---:|---:|---:|
|0|0/64|0/64|0/64|0/64|0/64|
|1|0/64|0/64|64/64|64/64|0/64|
|2|64/64|64/64|64/64|64/64|64/64|
|3|0/64|0/64|64/64|64/64|0/64|

seed2는발별출발/착지패드사이실제빈공간6cm를가진split에서모든기존도약조건을통과했고,최초네발의2cm투영도기대착지패드안에들어왔다. 평균몸체비행전진은continuous14.94cm/split14.74cm다. 전신15cm갭통과·연속파쿠르·실기성공으로표현하지않는다. 성공은동일개발군/단일학습seed결과이므로독립seed재현성이충분하다고주장하지않는다.

seed1과3은split에서정밀접촉과안정화를완료했지만평균비행전진11.09/11.31cm로최소거리12cm(15cm명령−3cm허용)에미달했다. 판정과허용치는변경하지않았다. seed0는split에서유효비행전비발충돌로모두실패했다.

seed0의continuous원본64episode모두도약전(stage0)발중심이분리발판의빈공간에해당하는위치에있으면서접촉력>5N/발중심높이2±1cm인표본이있다. scenario20000은FR0.455초에관측된다. split동일scenario는0.50초관측종료/비발충돌. 이는연속지지면을준비동작에사용하는의존성과일치하지만단일인과확정이나접촉쌍직접확인은아니다. 구의전체투영이빈공간내부였다는의미도아니다. scripts/p2_28_failure_report.py와원본진단JSON으로재생성가능하다.

다음P2-29 후보는기존네정책에서동일15cm목표를사용해continuous추가학습대조군과split추가학습군을비교하는것이다. split의5/10cm목표는빈공간에놓일수있으므로기존0–15cm연속명령분포를그대로사용하면안된다. 목표가실제착지면안에있도록새학습계약을명시하고,기존checkpoint에서새조건으로학습을시작하는fork와동일조건resume를구분해야한다. PPO rollout은현재정책으로새로수집하고과거실패궤적을직접replay하지않는다. 짧은거리능력은continuous혼합거리회귀군으로유지한다. 사전프로토콜/예산/복구·물리검증후착수하며현재는미구현·미실행이다. 이번결과만으로champion승격하지않는다.
