# P2-40 네 거리 학습에서 긴 목표 선택 비중 비교

P239의네거리학습에서15cm단일step이P238의54~67%로감소했다. 이것만으로성능저하를설명할수없지만고정된네목표내선택비중의효과를검증할수있다. 본문작성시구현·학습은시작하지않았다.

## 조건과 예산

대조는P239coverage seed0~3최종800의네목표균등선택이다. 처치는동일한0/5/10/15cm를정수ticket가중치[1,1,1,3]으로선택한다. 즉15cm는1/2,나머지는각1/6이다. reset확률을정의하며rollout step비율의정확한일치를약속하지않는다. P238과15cm reset확률은같지만제자리확률과중간목표가달라P238과의차이를단일원인으로해석하지않는다.

처치4seed는같은원P231부모800에서policy/critic/normalizer만새fork한다.1024환경×24step×800update×4=78,643,200새step. P239대조78,643,200재사용. geometry·chain:single50:50·보상·관측·PPO·탐험·성공판정은고정한다. 모델선택은최종800,실패seed포함. 단순재개로목표확률변경을허용하지않는다.

## 착수 검증

가중치strict계약,uniform기존경로보존,resetdraw분포와목표별실제step기록. 고정RNG의ticket경계매핑/배치reset/재개거부검사,64환경12update smoke 및2update재개,기존uniform실행회귀,1024환경60update프로파일링을한다. 평가·200Hz·64로봇camera4·result제목에가중치와phase:P2/step:p2-40-long-goal-weight 태그기록을確認한다. 검증실패는原attempt를보존하고본학습전에해결한다.

## 최종 평가와 판단

각モデルtwohopdeck64,単일deck/continuous0·5·10·15cm各16,split15×64. 새16+재사용대조16평가를같은시나리오/설정/계보/예산으로비교한다. 거리별성공률·純비행거리·첫접촉·안정화·학습노출·두번째도약step을보고한다. 개선이없으면기각하고보상또는목표간간섭의다른가설을분리해검토한다. 성공판정완화/실패seed제외/임의champion승격은하지않는다. 개발군실험이며연속갭파쿠르완료가아니다.
