seed1은 유효도약을 습득하지 못했고 최초접촉도64개 모두 미완료다. 이들을 착지 이후 분석에서만 별도 분리하고 전체 평가 분모에는 포함했다. seed0/2의64개씩, seed3의56개 안정화실패에서는 최초접촉 완료 후200ms 내 목표영역 이탈과 연속200ms 기하유지 부재가 확인됐다. 모든 성공8개는 최초접촉 발판내부 투영 검사도 통과했다. 이 검사는 접촉 쌍이나 지속 지지를 증명하지 않는다.

분석 코드 `post_landing_report.py`는 불완전 최초접촉을 명시적으로 기록하도록 수정했다. 기존 P2-20/21의512개 완전접촉 episode 진단 수치가 모두 동일함을 회귀 비교했고, P2-22의64개 미접촉 episode가 별도 집계되는 실제 사례도 검증했다.

마지막400update 훈련 성공/완료episode는 seed별61543/87774,0/49190,44585/74514,47635/78399였다. 훈련은 변화하는 정책·균등 목표분포·샘플링 행동이고 최종 평가는 고정 목표·평균 행동이므로 이 차이를 곧바로 평가 버그나 잡음 효과로 단정하지 않는다.

다음 구체 진단은 P2-20과P2-22의 고정 최종4seed 모델에 대해 동일64개 개발군에서 mean과sampled 행동을 비교하는 것이다. mean은 이번에 감사한 결과를 재사용하고 sampled는독립RNG20000/20001 두반복을 수집한다. 두 모델군 모두 bounded정책이므로 effective std를 복원된clamp분포에서 확인한다. 추가학습은 없고 RNG반복을 학습seed로 취급하지 않는다. 과거P2-19의 무제한std모델 결과를 이 모델에 그대로 적용하지 않는다. 결과 전 보상 가중치나 성공조건을 다시 바꾸지 않는다.
