# P2-32: 동결 정책의 리셋 없는 두 도약

넓은 동일 재질 발판에서 15cm 도약을 두 번 명령했다. 첫 착지 안정화 후 물리 상태를 보존하고 다음 절대 목표를 30cm로 갱신했다. 각 도약의 비행 이동 요구는 15cm이며 출발 반경은 기존 3cm를 유지했다. 추가 학습은 0 step이다. 연속 갭이나 Planner 성능 결과가 아니다.

| 학습 seed | 첫 도약 성공 / 64 | 두 도약 완주 / 64 | 두 번째 시도의 주요 결과 |
|---|---:|---:|---|
| 0 | 64 | 0 | 64건 출발 반경 위반 |
| 1 | 64 | 1 | 최초 발 접촉 정밀성은 64건 통과, 63건 시간 초과 |
| 2 | 64 | 0 | 64건 출발 반경 위반 |
| 3 | 0 | 0 | 첫 도약 실패로 두 번째 시도 없음 |

단일 도약 성공이 연속 실행을 보장하지 않았다. 특히 seed 1은 두 번째 최초 접촉까지 통과했으므로 seed 0·2의 출발 반경 문제와 구분해야 한다. 시간 초과 63건의 안정화·비행 거리 등 개별 미충족 조건은 추가 분석이 필요하다. 현재 결과만으로 모든 실패를 하나의 원인으로 확정하지 않는다.

## 구현 및 결과 검증

- 새 어댑터의 1회 도약 대조는 기존 seed 0 deck 평가의 64개 에피소드에서 모든 기존 지표가 정확히 일치했다.
- 총 192건의 첫 도약 전환에서 root/joint/velocity/actions/contact hysteresis/history/episode clock/env origins의 전후 tensor 동일성을 런타임에 검사했다.
- 독립 감사에서 전환 직전 200Hz 몸체 위치와 새 출발 원점, 전환 다음 샘플의 도약 번호·시작 step·절대 목표를 대조했다. 시나리오별 도약 순서, 종료 분모, 성공 조건, 시간 한도 및 artifact hash 검사를 4개 실행 모두 통과했다.
- 검사 스크립트: `scripts/audit_chained_evaluation.py`. 결과: `artifacts/p2-32-chain-main-audit.json`. 금지 simulator write/reset 호출 자체를 감시하는 별도 장치는 아직 없다. tensor 동일성 검증과 직접 구현 검토의 범위를 넘는 보장은 하지 않는다.
- 4개 최종 영상은 `result/`에 상세 제목으로 수집되었다. 영상 hash, render-enabled 64개, camera side 4를 확인했다. seed 1의 1.8초 프레임을 직접 확인했으며 전체 영상 육안 검수를 의미하지 않는다.

## 다음 작업

seed 1의 두 번째 시도에서 어떤 성공 조건이 남았는지 원시 기록과 지표로 분리한다. seed 0·2는 전환 후 준비 구간과 이륙 전 몸체 이동을 나누어 분석한다. 이후 실제 착지 상태에서 시작하는 학습 분포와 정적 초기상태 분포의 차이를 다루는 고정 예산 대조 실험을 사전 등록한다. 판정 기준 완화나 성공 seed만 선택하는 방식으로 현 실패를 제거하지 않는다.

추가 분석: seed 1의 두 번째 시간 초과 63건 모두 최종 오른앞발만 반경 밖이다. 비행 거리·최초 접촉·apex·높이·수직/각속도·지지 조건은 종료 시 통과했다. seed 0의 준비 구간 몸체 이동은 7.38~7.53cm다. docs/p2-32-failure-diagnosis.json 및 scripts/p2_32_failure_report.py 참조. 후속 P2-33은 같은 준비 시간에 직전 action 명령을 유지하는 단일 요인 대조다.
