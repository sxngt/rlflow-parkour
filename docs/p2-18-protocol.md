# P2-18 비행 이동·최초 착지 결합 보상

주요 실행 전 고정한 개발 실험. P2-17은15cm 비행 이동 조건을개선했으나첫접촉/안정화손실로전체성공0/0/3/0이었다. 가중치 증가 sweep 대신 이동과 착지를 함께 보상하는 구조 개입을 검증한다.

새 mode=coupled_first_touch_v1은 다음을 적용한다.

- 네 발 최초 비행 후 접촉이 모두 기록될 때, 기존 비행거리 보상을 대체하여 한 번만 지급한다.
- 보상은 `12 * exp(-abs(first_body_touch_travel-command)/0.03) * exp(-max(first_foot_errors)/0.05)`다.
- 이동은 최초 발 접촉 때 고정한 몸체 위치로 계산한다. 지급을 기다리는 동안 걸어간 거리나 이후 발 수정은 포함하지 않는다. 발 오차도각발200Hz 최초접촉에서고정한다.
- 네 발 중미접촉이있으면지급하지않고,실패/출발영역위반에는지급하지않는다. 실패와동시에기록되거나이미실패한episode는나중에보상을받지못한다. reset때만새지급기회를연다.
- 기존발별최초접촉보상과안정화/최종성공보상은유지한다. 따라서전체보상의크기·지급시점이변하는개입이며순수한동일크기가중치비교가아니다. 안정화는결합보상의직접조건이아니므로별도지표로검사한다.

기존 P2-17 weight12 거리전용4seed를 같은예산 대조로재사용한다. 새조건 fresh seed0–3,1024환경×24step×1600update,각39,321,600step,추가157,286,400step. 이전거리/출발반경커리큘럼,1.4×1.2m발판,초기calibration,관측·행동·PPO·나머지보상은같다. 성능참고로P2-16 weight4결과도보되사후최종시험주장하지않는다.

평가는동일64개개발episode,거리0/5/10/15cm×16높이명령,출발3cm,15cm최소실비행12cm,기존최초접촉반경과안정화기준을유지한다. 성공/비행거리/최초접촉/안정화/지지면포함을seed별로보고한다. rawreturn은보상구조가달라직접성과비교에사용하지않는다.

주요실행전에는부분접촉대기,지급일회성,최초접촉오차고정,실패차단,출발영역위반,선택reset,잘못된설정단위검사와짧은학습/재개/최종평가를검증한다. config.jump의새mode/scale은checkpoint엄격계약에포함되어이전모델을정상resume로가져오지않는다.
