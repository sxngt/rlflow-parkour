# P2-16 목표 거리 커리큘럼

주요 결과 확인 전 고정한 개발 실험이다. P2-15 발판 학습은 seed 3에서 48/64 성공했지만 나머지 세 seed는 0/64였다. 성공한 48회는 최초 발 접촉 구 투영이 발판 안쪽에 있다는 기하 진단도 통과했다. seed 3의 15cm 실패 16회는 접촉 정밀도와 안정화를 충족했으나 비행 이동거리가 부족했다. 이 결과만으로 지형이나 보상의 단일 원인을 확정하지 않는다.

이번 가설은 짧은 목표 거리를 먼저 학습하면 fresh 도약 학습의 seed 안정성과 후반 목표 수행이 나아지는가이다. 지형은 같은 1.4×1.2m 단일 발판, 동일 초기 calibration 및 관측/행동/보상/PPO 계약을 사용한다.

- 새 조건: seed 0–3, 각 1024환경 × 24step × 1600update = 39,321,600step. 총 추가 157,286,400step. fresh 초기화이며 기존 모델 가중치를 가져오지 않는다.
- 학습 목표 거리: update 1–400은 0–5cm, 401–800은 0–10cm, 801–1600은 0–15cm 균등 샘플링. 전체 평가 거리는 항상 0/5/10/15cm다.
- 기존 launch 반경 6→4.5→3cm 일정은 그대로 유지한다. 거리 또는 반경 전환 시 모든 환경을 reset하고 진행 중 episode를 버린다. 추가 reset도 이 커리큘럼 개입의 일부다.
- 대조군: 이미 완료된 P2-15 deck seed 0–3의 동일 예산 결과를 재사용한다. 동시 실행한 무작위 대조라고 표현하지 않는다. 코드 변경은 새 schedule가 없는 설정의 정책/환경 동작을 유지한다.
- 최초 검증은 64환경 3update에서 축소한 거리 전환 및 checkpoint 재개, 64개 병렬 최종 평가/200Hz trace/영상/아카이브를 확인한다. 이 smoke는 주요 비교에서 제외한다.
- 최종 평가: 같은 발판의 기존 개발군 64episode, 거리별16개 및 seed별 결과. 성공, 유효 비행, 최초 접촉, 실제 비행 이동거리, 안정화, 지지면 기하 진단과 총 step/GPU 시간을 보고한다. 평가군을 최종 시험군으로 주장하지 않는다.
- 64개 렌더링, camera-side4, result의 상세 제목과 phase:P2 / step:p2-16-distance-curriculum 태그를 유지한다.

사후 예산 연장이나 실패 seed 교체는 하지 않는다. 개선이 없으면 실패 원인과 초기 도약 능력 학습 경로를 다시 분석한다. 이 단계는 넓은 발판 도약의 기준선이며 좁은 지지면, 연속 갭, Planner를 구현했다고 주장하지 않는다.
