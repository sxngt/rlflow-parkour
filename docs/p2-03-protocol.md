# P2-03 · 첫 착지 정밀화

2026-09-11 본 학습 전 고정. P2-02는 도약 후 안정화에4seed 각각64/64 성공했으나 네 발 첫 접촉이 모두5cm 안인 사례는0이었다. 이번에는 첫 착지와 이후 위치 보정을 분리한다.

## 계약

새 task `a1_flat_jump_precise_v3`는 P2-02의 로봇·구동기·66차원 관측·물리200Hz/제어50Hz·4초 제한·높이 명령4–6cm·실패 조건을 유지한다. 유효 비행 판정 이후, 물리 갱신 직후 처음 발 합력이5N을 초과한 표본의 발 몸체 중심 XY와 목표 XY 차이를 발별로 고정한다. 이후 위치 보정·재접촉으로 이 오차를 바꾸지 않는다. 비행 전 접촉은 제외하고 episode reset에서 초기화한다. 이는 접촉 manifold 위치나 실센서 값이 아니다.

새 성공은 **기존의 연속0.2초 안정화 AND 네 발 모두 최초 접촉 오차5cm 이하**이다. 기존 안정화를 한번이라도 달성했는지는 별도 기록한다. 잘못된 첫 접촉만으로 즉시 종료하지 않고 기존 실패/시간 제한까지 진행한다. 목표 위치와 성공 반경은 줄이거나 넓히지 않는다.

보상은 P2-02의 모든 항을 유지하되 성공+8은 새 성공에만 지급한다. 각 발 첫 접촉에서 `2*exp(-first_error/0.08)`을1회 추가한다. 총 추가 보상은 episode당최대8이며 같은 접촉을 다시 보상하지 않는다. 실패 표본에는 추가분을 지급하지 않는다. 세부 수치는 본 학습 중 변경하지 않는다.

## 예산·평가

seed0/1/2/3 각각1024환경×24step×1600updates를 처음부터 학습한다. 신규157,286,400 환경step. 같은64개 개발 높이 명령, 마지막 checkpoint, deterministic 평가,16대 병렬 MP4 및200Hz 원본을 저장한다. P2-02 원본4seed를 같은예산 대조 자료로 사용한다.

새 성공률과 기존 성공률은 계약이 다르므로 그대로 비교하지 않는다. 공통 비교는 유효 비행·요구 높이·첫 접촉 오차 및 네 발 반경내 비율이다. 기존 안정화 달성은 별도로 보고한다. 새 terminal의 발별 최초 접촉 오차가 원본200Hz 사후 진단과 일치하는지 확인한다. 누락된 첫 접촉의 terminal 오차는-1로 표시하고 관측0오차로 해석하지 않는다. 모델 자동 승격은 없다.

## 구현 검사

순수 함수 검사는 비행전 제외·정확히5N 제외·1회 저장·나중 보정 거부·부분reset 격리를 확인한다. 실제시뮬레이터 합성 검사는 정지 거부·잘못된 첫 접촉 후 안정화의 새 성공 거부·실제 접촉 읽기·보상1회·정확한 첫 접촉과hold 성공을 확인한다. 합성 flight flag와 자세 주입은 정책 성능으로 세지 않는다. 별도64환경×2update 구현 확인 및 자동 평가/영상/진단은 본 예산에서 제외한다.

구현 결과: 순수 함수 포함27개 검사 통과. `artifacts/p2-03-precision-state-check.log`의 실제 물리 접촉 읽기·중복 보상 방지·잘못된 첫 접촉의 후속 보정 거부·정확한 첫 접촉 뒤 hold 검사를 통과했다. `p2-03-precise-implementation-check`의2update 및64개 자동 평가·MP4·200Hz 진단, 두 run의 hash/UUID/회수 감사도 통과했다. 짧은 정책은 유효 비행이 없어 첫 접촉 누락값과 사후 진단의 일치만 확인했으며, 실제 학습 정책의 양성 접촉 수치는 본 평가에서 추가 확인한다. 합성 검사는 정책 성과가 아니다.

첫 접촉 오차 latch는 보상·평가 경로에 있고66차원 정책 입력에는 추가하지 않았다. 정책 입력이 모든 과거 사건 정보를 포함한다고 주장하지 않는다. 관측 이력 연구는 후속 범위다.
