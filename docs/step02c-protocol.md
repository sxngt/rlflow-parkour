# P1 · Step 02c — 정렬 비용 적용 시점 비교

2026-09-11 사전 고정. 사용자 지시에 따라 평가 후 다음 연구를 지속한다. 이전 B의 최종 단계 전용 비용에서 진행이 정체되어, 동일 비용을 모든 단계에 적용한 C(v6)를 비교한다.

C 추가 reward: `-mean(min((XYerror/.025)^2,16))*dt`, lift·place·final 모든 단계. 이전 B와 비용 수식·가중치는 같고 stage gate만 제거한다. 지정 발의 XY 목표는 reset부터 같으며 다른 발 목표는 초기 위치 유지. 단계 진입 자체에 의한 추가 비용 불연속을 없애지만, 학습 성공이나 최적 정책 보존을 이론적으로 보장한다고 주장하지 않는다.

기존 A(v4)와 B(v5) FL/RL seed0/1 총8run을 그대로 재사용. 신규 C FL/RL seed0/1 4run을 각1024환경×24step×800updates 처음부터 학습한다(신규78,643,200steps). GPU0 FL0, GPU1 RL0, GPU2 FL1, GPU3 RL1. 비교에 포함한 전체12run 예산235,929,600steps. 추가 seed/과제는 별도 후속 프로토콜로 다룬다.

관측·행동·PPO·성공 판정·12초 episode·시나리오 분포는 동일. 이전 실험과 동일64개 개발군, 최종checkpoint, deterministic평가,200Hz진단,16대MP4. 발별1회 착지와0.2초4발안정화를 구분한다. 원본을 수정하지 않고 태그registry에 재사용 비교관계를 추가한다.

주요 판단: 착지 진행이 B 대비 회복되는지, 안정화가 A 대비 대응seed에서 나아지는지, 전 발 무접촉·낙상·지지오차가 악화하지 않는지. 두seed 결과를 모두 보고하며 선택한 실패 조건에 대한 탐색적 개발 결과임을 명시한다. 비용 감소만으로 성공을 선언하지 않는다.

계산 예산·설정은 도중 변경하지 않는다. 전 조건이 실패하면 벌점 크기 sweep을 무한 반복하지 않고 성공 정책의 데이터와 커리큘럼·관측·탐색 조건을 검토한다. C가 개선하면 미사용 학습seed에서 재검증 후 순차 연결 여부를 판단한다. 모델 자동승격 없음.
