# P2-09 · 수평 명령 범위 확장

학습 시작 전에 고정한다. P2-08 비행거리 보상군은3cm 출발 재평가에서5cm 목표16/16·14/16 성공을 얻었지만 제자리 seed1은10/16이고10/15cm는 모두 실패했다. 이제 실제 비행거리를 학습하는 명령 범위를 넓힌다.

P2-08 travel 설정에서 train_forward_range_m만0–5cm→0–15cm로 변경한다. 비행거리 보상4·scale3cm, 출발 반경6cm, 비행/첫접촉/안정화 성공 기준은 유지한다. 기존 checkpoint를 전이하지 않고 새 정책을 seed0/1/2/3으로 학습한다. 따라서 커리큘럼 전이 성공으로 표현하지 않는다.

각1024환경×24step×1600updates =39,321,600step, 총157,286,400 신규step. seed와GPU index를 동일 배치하며 UUID로 실행한다. worker 제한3600초, 종료 후64개 고정 평가·16로봇 MP4·200Hz 진단. 코드 변경 없이 검증된 환경의 명령 분포만 바꾸므로 별도 짧은 구현 run은 반복하지 않는다.

평가0/5/10/15cm 각각16개.10/15cm는 이번에는 학습 분포의 범위 안이다. 기존과 같은 manifest를 사용하고 pooled64를 독립시행으로 취급하지 않는다. 그림은 사전에 episode3(15cm)로 선택한다.

거리별 성공·실비행 이동·첫접촉·안정화·출발 위반을 함께 보고한다.0/5cm 회귀를 반드시 포함한다. P2-08과의 범위 비교는 공통 seed0/1에서 먼저 보고하고 seed2/3은 추가 재현성 자료로 구분한다. P2-08의 두 seed와 P2-09의 네 seed를 무조건 같은 표본 크기로 비교하지 않는다.

모든 모델은6cm 평가 이후3cm 출발 조건에서도 재평가한다. 성공한 모델만 고르지 않는다. 원본 좌표·artifact hash·GPU 회수를 검사하고 상세 제목 영상·태그를 보존한다. 모델 자동 승격 없음.

넓어진 명령 분포에서 비행이나 착지가 무너지면 단계적 거리 커리큘럼/명시적인 사전학습 전이를 검토한다. 같은 조건의 예산을 무한 연장하지 않는다. 거리가 확장되더라도 실제 발판·갭 geometry와 연속 계획은 후속 검증이며 평지 목표 도약을 파쿠르 완성으로 주장하지 않는다.
