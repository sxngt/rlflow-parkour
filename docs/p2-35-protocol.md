# P2-35: 연속 도약 학습 중 능력 유지의 시간 경과 진단

P2-34 최종 모델의 회귀가 초기부터 있었는지, 학습 중 생겼는지 확인한다. 신규 PPO 학습은 하지 않는다. 기존 정책과 원본 artifact는 변경하지 않는다.

- P2-34 chain seed 0~3 전체를 포함한다. 결과를 보기 전에 checkpoint 200/400/600을 고정한다.
- 각 checkpoint에서 deck 두 도약64개와 continuous 단일 0/5/10/15cm 각16개를 평가한다. 총24개 신규 평가,1,536 episode다. cp800은 P2-34 결과8개를 재사용 표시한다.
- 동일 부모 기반 설정·지원면 보정·평균 행동·기본자세 준비0.3초·출발/착지 판정을 유지한다. 환경 상태를 새로 생성하는 개발 평가이며 원본 학습 궤적 재생이 아니다.
- 4 GPU에 seed별 하나의 평가를 실행하고 각 GPU에서는 순차 처리한다. 평가당 timeout300초, 중복 실행 금지 및 기존 run_job lease/회수 규칙을 사용한다.
- 모든 실행200Hz 진단,64개 렌더링/camera_side4, 상세 제목 result 영상, phase:P2 및 step:p2-35-chain-retention-timeline 태그를 남긴다.
- 같은 seed/suite의 시나리오 일치를 검증하고 checkpoint별 전체 코스·첫 도약·거리별 성공과 실패 단계를 보고한다. 학습 step은0, 평가 비용은 별도 집계한다.

이 진단에서 가장 좋은 중간 checkpoint를 선택해 P2-34 사전 고정800 결과를 대체하지 않는다. 탐색적 시간 경과 분석이며 조기 종료나 커리큘럼 변경의 효과는 후속 동일 예산 실험에서 검증해야 한다. seed 간 변동을 병렬 episode 수로 축소하지 않는다.
