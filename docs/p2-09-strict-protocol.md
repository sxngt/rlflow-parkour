# P2-09 출발 범위 재평가 프로토콜

P2-09의 네 seed 최종 1600-update 모델을 모두 고정하여 평가한다. 성공 모델만 선택하지 않는다. 추가 학습은 없다.

체크포인트는 원래 학습 계약으로 복구한 뒤 평가의 jump.launch_radius_m만 0.06에서 0.03으로 좁힌다. 다른 성공 기준과 0/5/10/15cm 각16개 고정 평가 조건을 유지한다. 거리별로 같은 높이 명령을 짝지어 평가한다. 기본 평가와 별도 __strict-evaluation 경로를 사용한다.

거리별 성공·출발 범위·실제 비행거리·첫 접촉 오차·안정화를 보고한다. 원본 200Hz 상태와 launch/first-touch 기록의 일치를 검사한다. 16로봇 MP4는 result에 보존한다. trace는 사전 선택한 episode3(15cm)이다. 추가 학습 예산0, 평가 worker당600초 제한. 실제 갭이나 실기 결과로 해석하지 않는다.
