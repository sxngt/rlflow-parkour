# P2-37: 같은 거리 목표에서 지지면 조건 비교

질문: P2-34 연속 전용 모델과 P2-36 혼합 모델의0/5/10/15cm 단일 도약 성능이 넓은 deck과 발별 continuous 지지면 사이에서 어떻게 달라지는가? 과제 목표 범위와 지형 변화의 영향을 분리해 관측한다. 접촉 물리의 인과 원인을 확정하는 실험은 아니다.

- P2-34 chain 및 P2-36 mixed의 seed0~3 checkpoint800 전체를 동결한다.
- 신규: 각 모델을 deck에서 단일 도약, 0/5/10/15cm 각16개, 총8평가512episode. 학습 step0.
- 재사용: 각 모델의 기존 continuous regression8평가512episode. 동일64개 개발 시나리오의거리/초기조건/episode ID 일치 검증을 필수로 한다.
- 명시적1hop adapter, 평균 행동, 동일 보정·재질·PD·준비시간·판정,200Hz진단을 유지한다. 바뀌는 지지면 geometry 외의 평가 계약을 비교한다.
- 4 GPU에서 seed별두조건 순차실행. 각job300초제한. 64render/camera4,상세제목result,phase:P2/step:p2-37-support-transfer 태그.
- 거리별paired성공 차이와 출발·비행·첫접촉·안정화 실패를 보고한다. 먼저 끝난 episode만 선택하지 않는다. 신규 결과로 모델을 선택해 기존P236최종결론을 대체하지 않는다.

deck에서는 유지되고continuous에서실패하는조건이확인되면다음학습의지형분포를검토한다. 양쪽모두실패하면목표과제유지나학습안정성의문제를계속분석한다. 어느쪽결과도사전에보장하지않는다.
