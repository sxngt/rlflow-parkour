# P2-32 동결 정책의 두 도약 연속 실행 진단

P2314개정책을가중치/normalizer갱신없이사용한다. 새학습step0. seed0~2의단일도약검증을통합진단의근거로삼되seed3도모든평가에포함하고기존15cm실패와구분한다.

## A. 단일 도약 지형 대조

기존matched-material deck(140×120cm)에P231각최종정책으로15cm×64고정높이명령을평가한다. 비교는이미있는P231split15cm×64와동일시나리오다. 접촉재질/보정/제어주기/정책/성공판정은유지한다. 넓은발판을선택한이유는첫전환진단에서두번째목표를물리적으로지지하고새갭생성의기하효과를분리하기위함이다. 이단계는갭연속통과성과가아니다. 실패한seed를제외하거나자동재학습하지않는다.

## B. 두 도약 전환 계약 (구현·검증 전)

동일deck에서사전지정목표는명목발위치+15cm,이후+30cm이다. 첫도약이기존정밀최초접촉/안정화/비행거리조건을통과했을때만두번째로진행한다. 첫성공은course성공이아니다. 각도약4초한도/전체8초,최종성공은두번째안정화조건충족이다. 시간제한/실패/완료를상호배타적으로기록한다.

전환은제어step경계에서처리한다. root pose/velocity/joint state,직전행동,실제접촉관측·sensor timestamp·history·물리시간을보존한다. simulator reset,관절상태쓰기,접촉력조작,env origin이동을사용하지않는다. 도약별phase/flight/first-touch/travel/hold/event누계만재초기화하고새목표와local clock을설정한다. 첫도약출발기준은기존보정원점,둘째는전환시실제몸체XY로명시한다. 도약거리판정은각구간의launch→first-touch로계산한다. 고정된세계좌표발목표와현재몸체기준참조를구분한다.

두번째에도0.3초준비시간을적용하며이기간은기존기준자세PD명령을실행한다. 이는즉시반동연속점프가아닌착지안정화후재도약진단이다. 기존상승/착지높이기준은동일평면의보정높이를유지한다. 전체경로의기존0.6m이탈제한은두번15cm진단범위에유지한다.

검증:transition전후동일physics시각의root/joint tensor불변,금지된write/reset호출없음,도약ID와시간연속성,stale first-touch/flight latch불사용,두번째launch기준의정확한마스킹,성공첫도약시auto-reset억제,실패전환억제,완료episode분모유지. 단일도약모드가A와동일계약/결과인지먼저검사한다. 원시200Hztrace에segment ID/목표/전환이벤트를남기고50Hz제어step과연결한다. 기존episode단위성공을단순히두번세어연속성공으로보고하지않는다.

최초B구현은축소episode검증후4seed×64고정시나리오진단. 난이도/높이명령은A와같은개발군이며최종시험군이아니다. 결과는첫도약성공수,두번째시작수,두도약성공수,전환후실패단계/지연으로구분한다. 추가학습이나Planner는이진단결과후설계한다.

전실행에phase:P2/step:p2-32-chained-execution 태그,checkpoint hash/terrain/material/원시진단/result상세영상64render/camera_side4를남긴다. B용collector/영상/감사와새성공스키마는명시적별도계약으로구현하며기존단일도약데이터를변경하지않는다.
