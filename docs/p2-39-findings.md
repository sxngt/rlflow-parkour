# P2-39 결과: 균등 네 거리 확장 기각

[고정 예산 비교](p2-39-comparison.md), [전체 검증 데이터](p2-39-comparison.json), [사전 프로토콜](p2-39-protocol.md). 새4개 학습78,643,200step과 재사용대조동일예산을 분리했다. 전체32평가의 같은시나리오/800 checkpoint/정책mean실행/200Hz기록/result MP4·이벤트 hash/64환경camera4를 감사했다. 개발군이며 독립학습seed는4개다.

거리0/15를0/5/10/15로 균등 reset 샘플링한 조건은 채택하지 않는다. 연속deck완주64/42/63/0→64/0/0/0, continuous 단일 회귀64/64/48/48→64/48/46/16, split15 성공0/64/64/64→모두0이었다. seed0은 동일하지만 나머지seed의회귀와긴목표성능은저하됐다. 새로운champion으로등록하거나중간checkpoint를골라결론을바꾸지않는다.

## 실패 조건

artifacts/p2-39-native-first-hop-diagnosis.json과 native-second-hop-diagnosis.json 참조. seed1/2/3 각64개첫도약은출발영역,유효비행,첫접촉정밀도,최종발반경,지지,안정화조건을통과했지만비행이동거리조건을모두충족하지못했다. 따라서두번째도약으로전환하지않았다. seed0은64개모두두도약통과했다. 이분류는종료조건의근거이며어떤학습신호가원인인지는별도검증이필요하다. 실패를낙상으로통칭하지않는다.
