# T0S-v2 순차 발 디딤 파일럿 — 2026-09-10

A1이 평지에서 FR→RL→FL→RR 순서로 발을 들어 목표에 내려놓는 과제다. 접촉 상태와 연속 공중/착지 표본으로 진행을 판정한다. 과제 계약은 [T0S-v2](t0-sequential-v2.md)를 따른다. 도약이나 불연속 지형 통과 결과는 아니다.

네 RTX 4090에 독립 seed 하나씩 배치했다. 각 run은 1,024환경 × 24 control steps × 800 PPO updates = 19,660,800 steps이며, 비교 학습 총예산은 78,643,200 steps다. 병렬 환경들은 한 정책을 공유하며 독립 학습 seed로 세지 않는다.

| 정책 | 고정 개발군 완주 | 평균 완료 접촉 / 4 | 평균 episode 시간 |
|---|---:|---:|---:|
| 기본 자세 대조군 | 0/64 | 0.00 | 12.00 s |
| seed 0, 800 updates | 64/64 | 4.00 | 1.29 s |
| seed 1, 800 updates | 64/64 | 4.00 | 1.32 s |
| seed 2, 800 updates | 0/64 | 1.09 | 12.00 s |
| seed 3, 800 updates | 0/64 | 2.97 | 12.00 s |

모든 조건에서 정의된 낙상 종료는 0건이며 미완주는 시간초과다. 같은 64개 개발 시나리오를 평가했고 각 환경의 첫 episode만 집계했다. 두 seed는 해결했지만 나머지 두 seed는 부분 진행에 머물렀다. 따라서 안정적으로 수렴하는 학습이라고 결론내릴 수 없다. 개발군 결과이며 최종 시험 또는 미지 조건 일반화 주장이 아니다. episode별 결과와 Wilson 구간은 각 evaluation.json에 보존한다.

## 영상

[실행별 영상 목록](../result/README.md)에 모델·seed·업데이트 수를 포함한 자세한 제목으로 보관했다. 새 최종 평가 영상은 고정 4×4 구역의 16개 로봇을 보여준다. 학습 후 고정 정책의 평가 영상과 실제 PPO 업데이트 중 촬영한 영상은 따로 표시한다.

실제 학습 촬영은 seed 0의 800-update checkpoint에서 별도 attempt로 25회 재개했다. 1,024환경 중 16개를 촬영했으며 1280×720, 25 FPS, 300 frames(12초)다. 추가 614,400 steps는 위 동일 예산 비교에서 제외한다. 825-update 모델의 후속 개발군 평가도 64/64 성공이다.

## 검증 및 후속

접촉 이벤트·시나리오·결과 보관 테스트 11개 통과. 학습 4건, 최종 평가 4건, 대조군 1건, 촬영 학습/후속 평가 2건의 checkpoint/artifact hash·계보·평가 완전성·GPU 할당 및 해제 검사를 통과했다. 실제 학습 영상의 길이와 해상도는 ffprobe로 확인했다.

정답 상태, 평지, 짧은 목표 이동, 현재 충돌 설정에 한정된 결과다. 다음 단계는 seed 2/3의 미완료 단계 분석과 수렴 편차 축소이며, 이후 발판·단일 도약으로 난이도를 확장한다.
