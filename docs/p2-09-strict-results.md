## 해석 및 다음 판단

3cm 조건에서 성공은 seed0/1/2/3 각각32/64·18/64·33/64·32/64이다. 5cm 명령은 모든 seed16/16 유지됐다.
15cm는 모든 seed0/16이며 모두 비행 확인 시 출발 범위를 초과했다. 6cm 학습 모델의15cm 성공이3cm 조건까지 일반화되지 않았다.
10cm는 seed0/2에서16/16 유지됐고 seed1/3은 출발 범위 초과로0/16이다. 제자리는0/16·2/16·1/16·16/16이다.
출발 위치는 실제 이륙 순간이 아니라20ms 비접촉과 높이·상승속도를 만족한 비행 확인 시점이다. 이를 지면 위 이동량 자체로 해석하지 않는다.
네 엄격 평가 artifact 감사와 원본200Hz 좌표 대조를 통과했다. 추가학습0. 자동 champion 승격 없음.

## 범위·재현

개발 조건의 탐색적 실험이다. 평가 episode 수와 독립 학습 seed 수를 구분하며 최종 시험 결과로 주장하지 않는다. 같은 발의 평가 시나리오가 동일함을 확인했다. 설정·checkpoint·원본200Hz NPZ는 artifacts, 최종16대병렬영상은 result에 보존한다. 재사용 대조군 원본은 변경하지 않는다.
