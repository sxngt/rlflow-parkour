# P2-29-REGRESSION 최초 착지 지지면 진단

거리 0/5/10/15cm × 높이 명령 16개의 동일 개발군을 사용한다. 원시 200Hz 최초 접촉 오차를 저장된 KPI와 1e-5m 이내로 대조했다.

| 조건 | seed | 기존 성공 / 64 | 첫 접촉 네 발 투영 포함 | 성공과 포함 모두 |
|---|---:|---:|---:|---:|
| parent | 0 | 48 | 64 | 48 |
| train-continuous | 0 | 64 | 64 | 64 |
| train-split | 0 | 64 | 64 | 64 |
| parent | 1 | 48 | 64 | 48 |
| train-continuous | 1 | 48 | 48 | 48 |
| train-split | 1 | 49 | 64 | 49 |
| parent | 2 | 64 | 64 | 64 |
| train-continuous | 2 | 48 | 48 | 48 |
| train-split | 2 | 48 | 48 | 48 |
| parent | 3 | 48 | 64 | 48 |
| train-continuous | 3 | 48 | 48 | 48 |
| train-split | 3 | 48 | 48 | 48 |

포함은 발 중심 높이 2±1cm 및 발판 가장자리에서 2cm 여유를 확인한 기하 진단이다. 실제 접촉 쌍이나 착지 이후 지지 지속을 보장하지 않는다. 평지에는 XY 경계가 없다. 이 진단은 기존 성공 정의를 소급 변경하지 않는다.
