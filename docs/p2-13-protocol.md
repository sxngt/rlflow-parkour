# P2-13 · 대규모 환경 minibatch 비교

P2-12는 같은 환경step을 약6분에 처리했으나 네seed 모두 유효비행/성공0/64였다. minibatch가8배 커지고 전체gradient 갱신이1/8로줄어든점의영향을 검사한다.

P2-12에서 num_mini_batches만4→32 변경(태그제외). 새정책seed0–3,8192환경×24step×200updates=각39,321,600step. epoch5,초기lr.001 adaptive,커리큘럼101/151에4.5/3cm,총예산고정. gradient minibatch 표본수는196608/32=6144로P2-11과동일하며gradient 갱신수200×5×32=32000으로P2-11의1600×5×4와같다. 데이터사용epoch는5로유지한다.

그러나새로운정책으로데이터를수집하는횟수는200으로여전히다르며,같은batch에서32회갱신하므로P2-11과동일알고리즘조건이라고표현하지않는다. 실패원인하나를확정하는실험도아니다. 비교대상P2-12는그외설정동일하여minibatch변경효과를직접검사한다.
