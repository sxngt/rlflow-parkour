# P2-02 · 요구 도약 높이와 착지 자세 보상

2026-09-11 본 학습 전 고정. P2-01은 모든 평가에서 비행과 재접촉을 했으나, 상당수가 요구 높이에 못 미쳤고 전부 낮게 웅크린 자세로 종료했다. 첫 착지 위치도 부정확했다. 본 실험은 앞의 두 병목을 겨냥한 결합 보상 수정이다.

## 변경과 고정 조건

새 task `a1_flat_jump_shaped_v2`. 물리·구동기·센서·66차원 관측·PPO·4초 episode·4–6cm 높이 명령·성공 및 실패 조건은 P2-01과 같다. 가중치는 다음 두 항만 추가한다.

1. 비행 apex 진행도 `p = clip((apex - 0.03)/(required_apex - 0.03), 0, 1)`. episode 내 이전 최대 진행도보다 증가한 양에 3을 곱한다. 총 추가 보상은 episode당 최대3이며, 착지 후 재도약이나 반복 호출로 다시 얻지 않는다. apex는 기존 유효 비행 이후 최초 착지 전 값만 사용한다. 실패 표본에는 이 보상을 지급하지 않는다.
2. 최초 착지 후 몸체 높이 비용 `0.5 * min((height_error / 0.06)^2, 4) * dt`. 비행 중에는 적용하지 않는다. 정상 높이에서는0이고, 최대 초당2의 비용이다.

높이 명령이나 성공 허용 범위를 낮추지 않는다. 두 항을 결합하므로 결과는 결합 수정의 효과이며 개별 항의 인과 효과는 별도 절제 실험이 필요하다. 첫 접촉 위치는 보조 지표로 계속 보고하고 최종 위치 정렬을 첫 착지 정밀성으로 표현하지 않는다.

P2-01과 명령 manifest가 동일함을 확인한다. 유효비행, apex 명령 충족, 재접촉, 최종 안정화, 첫 접촉 오차, 몸체 높이, 비발 접촉을 보고한다. 자동16대 병렬 MP4·200Hz 진단·hash/자원 회수 감사를 수행한다. 성공률이 낮아도 임의로 예산을 연장하거나 중간 checkpoint를 좋은 결과로 선택하지 않는다. 새로운 비교는 별도 프로토콜로 진행한다.
