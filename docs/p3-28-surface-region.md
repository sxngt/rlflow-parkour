# P3-28 — Shared-surface region traversal

User requests long, varied shared platforms, rather than one tiny pad assigned to each foot. P3-25/27 retain a6cm point-target evaluation. This explicit new experiment tests traversal using the exposed, safe region of the selected surface. It is NOT a6cm accuracy success and must not be pooled into that metric.

Unchanged:105-channel observation, point targets as soft guidance, PPO/reward/action contracts, front/rear sequence,60ms either-foot intermediate dwell, final four-foot contact and200ms body stabilization, all nonfoot collision failures, physics200Hz and measured flight events, ten-transfer easy geometry. Changed: selected-surface contact does not additionally require Euclidean distance≤6cm from its guiding point. It requires localXY within the2cm inset, normal offset0..4cm, normal force>5N, and selected-plane projection not inside/on another cuboid. This projection check prevents crediting an occluded lower platform or ambiguous coplanar overlap; it is geometric attribution, not direct simulator contact-pair measurement.

Training has no point-radius curriculum. Point distance is still logged as an error, but is not the success gate. Evaluation explicitly writes contact_target_mode=surface_region and evaluation_contact_radius_m=null. The web names the distinction. Initial rear stance can be accepted on the starting surface without forcing the rear feet to the old front-foot coordinates; soft target guidance remains unchanged.
