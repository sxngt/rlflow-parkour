# P2-21 후반 학습 거리 상한 확장

P2-20의 조사한 checkpoint800/1200/1600에서 15cm 성공은 모두 없었다. 최종 모델은 해당 거리에서 최초 접촉 정밀도와 안정화를 충족했지만 기록된 비행 거리가 최소12cm에 미달했다. 학습 분포 끝점의 거리 부족이라는 가설을 검증한다. 이것이 원인으로 확정된 것은 아니다.

P2-20과 비교해 update801–1600의 목표 거리 균등 분포만 [0,0.15]m에서 [0,0.20]m로 변경한다. 초기1–400의 [0,0.05]m,401–800의 [0,0.10]m, 출발 반경 일정, 탐색 상한 일정, 결합 보상, 성공 판정, 로봇·센서·지형·초기상태·PPO를 유지한다. 물리적으로 불가능한 조건을 해결했다고 주장하지 않는다. 더 어려운 명령이 기존 능력을 악화할 가능성도 평가한다.

fresh seed0–3,각1024환경×24step×1600update=39,321,600step, 총추가157,286,400step. P2-20 네seed를 재사용 대조로 한다. 더 넓은 목표 분포 때문에 동일 거리 구간의 학습 비중도 달라지는 개입이다. 상한 효과와 표본 비율 효과를 따로 분리했다고 주장하지 않는다.

최종 평가는 기존0/5/10/15cm 각16개 총64개 개발군을 그대로 사용한다. 20cm 성능을 본 실험의 결과로 주장하지 않는다. 15cm의 최소 비행 거리 충족, 정밀 최초 접촉, 안정화와 성공 수를 함께 비교하고 짧은 거리의 회귀를 보고한다. 학습 중 성공 및 네 seed의 차이도 기록한다. 예산 연장·실패seed 교체·최종평가 조건 완화는 하지 않는다.

주요 실행 전에64환경3update로 일정 전환을 축소한 smoke를 수행해 거리20cm/reset/탐색cap/유한 loss와 최종 평가 파이프라인을 점검한다. 실제 주요 설정의801 전환도 별도로 확인한다. 각 최종 평가에200Hz진단·64개 렌더링/camera_side4·상세 제목 result 영상·phase:P2/step:p2-21-distance-extension 태그를 남긴다. 완료 후8개 artifact감사와 비교·접촉 지지면 보고서를 생성한다.
