# P2-17 비행 거리 보상 강화 결과

기존 비행 거리 보상 가중치4→12 변경은 채택하지 않는다. 동일 예산에서15cm의 실제 비행 이동 조건은 개선됐지만 정밀 착지·안정화가 악화하면서 전체 성공은 감소했다. 다음 연구용 후보이며 운영 champion 승격 대상이 아니다.

| 지표 (각 /64, seed0/1/2/3) | weight4 P2-16 | weight12 P2-17 |
|---|---|---|
| 전체 성공 | 32 / 1 / 48 / 5 | 0 / 0 / 3 / 0 |
| 유효 비행 | 64 / 64 / 64 / 64 | 64 / 64 / 64 / 64 |
| 네 발 최초 접촉 정밀 | 64 / 47 / 64 / 16 | 16 / 15 / 4 / 32 |
| 안정화 경험 | 64 / 4 / 64 / 38 | 0 / 0 / 30 / 0 |
|15cm 실제 이동 충족 (각 /16)|0 / 0 / 0 / 0|2 / 16 / 16 / 16|
|15cm 전체 성공 (각 /16)|0 / 0 / 0 / 0|0 / 0 / 0 / 0|

새 조건 성공3회는 모두 seed2의5cm 목표다. 성공 사례는 최초 접촉 시 구 투영의 발판 내부 포함 검사도 통과했다. 지지면 기하 진단은 접촉 쌍 또는 지속 지지의 증명이 아니다.

각 run39,321,600step,새4run157,286,400step을 사용했다. 기존대조는동시무작위실행이아닌P2-16 재사용이며 동일시나리오·seed별 비교다. 전체8artifact감사와4최종영상hash를 확인했고 result의 seed1 0.8초 프레임으로 구도를 확인했다. 학습 return은 가중치 변경에 따라 의미가 달라져 주된 비교지표로 사용하지 않는다.

## 후속 방향

현재 TravelLandingReward는 네 발의 첫 접촉이 모두 확인되기 전, 첫 발 접촉 때 기록된 몸체 이동으로 보상을 지급한다. 발별 정밀도 보상은 별도로 더해진다. 결과는 거리 보상 강화와 착지 지표 사이의 손실을 보여주지만 이 지급 구조가 유일한 원인이라는 증명은 아니다.

다음 실험에서는 거리 보상을 네 발 최초 접촉이 모두 기록될 때까지 보류하고, 저장된 첫 비행 이동과 최초 발 접촉 오차를 함께 반영하는 결합 보상을 검토한다. 기존성공기준을완화하지않으며, 미접촉/실패/반복접촉으로 보상을 얻지 못하도록 검사해야 한다. 단순 가중치 증가 sweep은 여기서 중단한다. 새 방식은 보상 크기·지급 시점이 달라지는 구조 개입임을 밝히고 별도 프로토콜/검증 후 실행한다.
