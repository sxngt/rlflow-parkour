# P2-16 결과 해석

동일 예산의 목표 거리 커리큘럼에서 유효 도약이 네 seed 모두 나타났지만 정밀 착지·안정화·전방 이동의 결합 성공은 여전히 seed에 민감했다. 안정적인 Tracker나 갭 통과를 달성했다고 볼 수 없다.

| 조건 | seed 0 | seed 1 | seed 2 | seed 3 |
|---|---:|---:|---:|---:|
| 기존 고정 거리 성공 /64 | 0 | 0 | 0 | 48 |
| 거리 커리큘럼 성공 /64 | 32 | 1 | 48 | 5 |
| 기존 고정 거리 유효 비행 /64 | 0 | 0 | 64 | 64 |
| 거리 커리큘럼 유효 비행 /64 | 64 | 64 | 64 | 64 |

기존 대조를 재사용한 개발 비교이며, 네 학습 seed를 256개 독립 seed처럼 취급하지 않는다. 각 학습은39,321,600step, 추가 네 학습157,286,400step이다. 학습4개와 평가4개 artifact 감사, checkpoint/200Hz trace/영상 hash 검증을 통과했다. result의 주요 최종 영상4개를 확인했고 seed2의0.8초 프레임으로64개 활성화/camera-side4의 구도를 확인했다.

## 실패 구분

- seed0: 0/5cm 각16/16 성공, 10/15cm는 각각0/16. 최초 접촉과 안정화는 모두 충족했으나 실제 비행 이동이 부족했다.
- seed1: 5cm에서1/16만 성공. 0cm 첫 접촉 정밀도가 실패하고, 전체 안정화는4/64였다. 15cm에서는 비행 거리도 부족하다.
- seed2: 0/5/10cm 각16/16 성공,15cm0/16.15cm의 평균 실제 비행 이동11.66cm로 기존 성공 계약의최소12cm에 미달했다. 최초 접촉과 안정화는 모두 충족했다. 가까운 실패라고 성공으로 재분류하지 않는다.
- seed3: 0cm5/16만 성공.5/10/15cm에서 네 발 최초 접촉 반경 조건을 충족하지 못했다. RR 최초 접촉 오차 평균6.86cm, 반경5cm 안쪽16/64. 전체 안정화38/64. 기존 같은 seed의48/64보다 낮다.

모든 신규 성공 사례는 최초 접촉 시 발 구 투영이 발판 안쪽이라는 기하 검사도 통과했다. 이 검사는 접촉 쌍 식별이나 전체 착지 기간의 지지 보장이 아니다. 원시 진단에서20ms 이상 네 발 무접촉과 환경의 유효 비행 정의는 구분한다.

## 다음 진단

1600update의 결과만으로 거리 커리큘럼 중간에 능력을 얻었다 잃었는지 판단할 수 없다. 같은 네 run의800/1200checkpoint를 최종과 동일한3cm 출발 반경·0/5/10/15cm 개발군에서 추가 평가하는 것을 다음 과제로 둔다. 평가 전용이며 학습 step을 추가하지 않는다. 이 평가로 최고 checkpoint를 고르면 개발 선택으로 명시하며 최종 시험 성능으로 주장하지 않는다. 다른 학습 단계의 훈련 분포·반경과 고정 평가 조건도 구분한다.

이 진단 전에는 같은 seed를 임의 연장하거나15cm의 성공 기준을 완화하지 않는다. 도약 습득, 비행 이동, 첫 접촉, 안정화 중 어떤 조건이 학습 경계에서 악화하는지에 따라 다음 학습 개입을 정한다.

상세 결과: [평가 보고서](p2-16-results.md), [지지면 진단](p2-16-support-diagnosis.md), [사전 프로토콜](p2-16-protocol.md).


## 중간 체크포인트 진단 완료

사전 추가진단 범위800/1200×4seed의8평가가 완료됐다. 같은3cm 반경·64episode에서 seed별800→1200→1600 성공 수는0:32→32→32,1:31→32→1,2:18→0→48,3:24→0→5다.15cm는 모든중간/최종모델에서0/16. seed1은후반안정화32→4,seed3은800→1200첫접촉정밀48→0으로악화했다. seed2는후반회복하므로일률적조기종료를해결책으로단정하지않는다. 최종 조건에서 측정한 퇴화이며 특정 커리큘럼 변경의 인과효과는 분리하지 못한다.

8artifact감사와8result영상hash검증통과. [상세 비교](p2-16-checkpoint-results.md). 다음은동일구간의정책업데이트크기/학습률/관측normalization과착지안정화상태를점검해후속학습개입을정한다. 추가학습은아직시작하지않았다.


## 업데이트·정규화 진단

전체64checkpoint(100update 간격×4seed)의hash를검증하고학습률/actor상대L2변화/normalizer상태를정리했다. scripts/p2_16_update_diagnosis.py 및 p2-16-update-diagnosis.json 참조. 저장시점학습률은 seed0 1e-5–3.844e-4,seed1 1e-5–5.767e-4,seed2 1e-5–3.844e-4,seed3 1e-5–2.563e-4. seed3의1200/1600시점은2.25e-5/1e-5로,퇴화를공통적인고학습률사건으로설명할근거는없다. 저장시점값은update중최대학습률이나실측KL이아니며인과효과를증명하지않는다. normalizer count는모든seed에서연속증가했고일정전환초기화는없었다.

seed1의1200→1600마지막표본에서발목표반경위반32→56,지지이력위반0→31이늘었다. seed3의1200은첫접촉정밀도실패와함께최종발위치반경위반48/64였다. 최종표본진단만으로전구간원인을확정하지않는다. 다음실험P2-17은모든seed/중간모델에남은15cm비행부족에대해기존일회성비행거리보상의비중만4→12로높여검증한다. 착지성능손실도같이보고하고성공기준은유지한다.
