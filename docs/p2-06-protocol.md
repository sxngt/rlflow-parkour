# P2-06 · 학습 거리 범위 진단

2026-09-12, 학습 시작 전에 고정한다.

P2-05는 네 seed 모두 수평 도약 성공0/64였다. seed1은 유효 비행64/64와 출발 영역64/64를 만족했지만 정밀 첫 접촉은1/64, 안정화는0/64였다. 나머지 세 seed는 유효 비행0/64였다. 이는 출발 영역 위반 종료로 설명되지 않는다. 전 발 무접촉과 유효 비행은 다른 지표다.

## 질문과 조건

넓은 목표 거리 분포가 기본 도약 학습을 어렵게 하는지 검사한다. DirectedJumpEnv, 보상, 출발 반경3cm, 비행 이동 허용 오차3cm, 첫 접촉 반경5cm, 안정화 기준은 P2-05와 동일하다. 새 정책을 학습하며 checkpoint 전이는 없다.

- zero: 목표 거리 항상0cm, seed0/1, GPU0/1.
- short: 목표 거리0–5cm 균등 분포, seed0/1, GPU2/3.
- 각각1024환경 ×24step ×1600updates =39,321,600step. 총157,286,400 신규step.
- 각 worker 시간 제한3600초. 종료 후64개 고정 평가,200Hz 기록,16로봇 MP4.

평가 명령0/5/10/15cm 각각16개이며 P2-05와 같은 높이 명령을 사용한다. zero의 비영 거리, short의10/15cm는 학습 범위 밖 전이 진단이다. 기본 학습 회복 여부는 먼저0cm에서, 짧은 거리 학습은5cm에서 판정한다. 결과를 합친 성공률만으로 두 조건을 서열화하지 않는다. 두 seed는 탐색적 비교이며 일반적인 효과를 확정하지 않는다.

## 판정과 다음 분기

유효 비행, 출발 영역, 실제 비행 전방 이동, 첫 접촉 정밀도, 연속 안정화를 분리한다. 원본200Hz와 온라인 좌표·첫 접촉 오차를 대조하고 모든 실행을 감사한다. 사전 선택 그림은 episode1의5cm 명령이다.

zero에서 기본 능력이 회복되고 short가 저하되면 단계적 거리 커리큘럼 또는 명시적인 사전학습 전이를 검토한다. zero도 실패하면 수평 이동 shaping을 추가하기 전에 출발 제약과 비행 검출·보상 유인을 조사한다. short가 성공하면 더 긴 거리로 단계적으로 확장한다. 실패 결과도 보존하며 자동 champion 승격은 하지 않는다.

이 실험은 평지 목표 이동이며 실제 갭이나 발판을 통과하는 실험이 아니다. 학습 도중 기준·보상·예산을 변경하지 않는다.
