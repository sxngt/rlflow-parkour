# P2-22 착지 이후 가장 큰 발 오차를 기준으로 한 정밀도 보상

P2-20/21의200Hz 진단에서 안정화 미달173개 모두 최초접촉 완료 후200ms 안에 영역 이탈이 관찰됐다. 최초접촉 정밀도와 착지 이후 목표 유지는 분리할 필요가 있다. 특정 오른쪽 뒷발에 추가 가중치를 주지 않는다.

기준은 P2-20이며 거리0–15cm와 탐색 상한 일정을 유지한다. 기존 dense precision은 `mean(exp(-(foot_error/0.06)^2))-1`이다. `landed=true` 이후에만 이를 `min(exp(-(foot_error/0.06)^2))-1`로 바꾼다. 네 발을 대칭적으로 취급하며 범위는[-1,0], 기존 step_dt 곱도 유지한다. 가장 큰 발 오차가 전체 평균에 희석되는 것을 줄이는 단일 aggregation 변경이다.

`landed`는 기존 제어기의 비행 이후 착지 상태이며 네 발이 모두 정밀하게 착지했다는 뜻은 아니다. 착지 이전의 precision, 도약·최초접촉·거리·성공 보상과 종료 조건은 유지한다. 보상 강도의 분포도 달라지는 개입이므로 단순 정보량 효과로 표현하지 않는다. 한 발의 오차를 줄이려다 다른 동작을 악화하거나 착지를 회피하는지 평가한다.

새 설정 `jump.landing_precision_mode`는 기존 strict jump checkpoint 계약에 포함된다. 누락 시 기존 mean 동작을 유지하고 알 수 없는 값은 거부한다. 단위 검사는 이전 동작 보존·phase 선택·한 발 오차 희석 방지·발 순서 교환 불변성·동일 오차·잘못된 모드 거부를 검증한다. 짧은 학습/재개/평가 smoke 후 주요 실행을 시작한다. 짧은 smoke에서 학습 성능을 주장하지 않는다.
