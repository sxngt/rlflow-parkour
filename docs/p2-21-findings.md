# P2-21 결과 판단

학습4개와 최종평가4개가 완료됐고 `artifacts/p2-21-audit.jsonl`의8개 감사가 통과했다. 각 학습은39,321,600step, 총추가157,286,400step이다. 최종영상4개의 hash·64개 렌더링·camera_side4를 확인하고 seed0의0.8초 프레임을 검토했다. 비교·높이·최초접촉 지지면 보고서도 생성했다.

| seed | 기존 P2-20 성공 /64 | P2-21 성공 /64 | 정밀 최초접촉 | 안정화 | 15cm 성공 /16 |
|---|---:|---:|---:|---:|---:|
| 0 | 48 | 0 | 64 | 0 | 0 |
| 1 | 48 | 12 | 64 | 18 | 0 |
| 2 | 24 | 44 | 64 | 44 | 8 |
| 3 | 22 | 48 | 64 | 64 | 0 |

모든 seed에서 유효비행64/64와 최초접촉 정밀도64/64를 유지했다. seed2는15cm에서 최초로8/16성공했으며 실제 평균 비행거리13.20cm, 거리 기준 충족16/16이었다. 다른seed의15cm 평균 비행거리는 seed0 9.07cm, seed1 9.82cm, seed3 8.43cm로 최소12cm에 미달했다.

seed별 성공 평균은35.5/64에서26/64로 감소했다. seed0/1의 큰 회귀 때문에20cm 상한 확장을 안정적 기준선으로 채택하지 않는다. P2-20을 후속 비교 기준으로 유지하고 P2-21 seed2는15cm 실행 가능성의 관찰 사례로 보존한다. seed를 골라 비교의 결론을 바꾸거나 champion으로 승격하지 않는다. 현재는 넓은 단일 발판의 개발군 평가이며 실제 갭·연속 파쿠르 성능이 아니다.

변경 직전 checkpoint800의 정책과 정규화 tensor가 네seed 모두 대응P2-20과 일치했다(`artifacts/p2-21-preintervention800.json`). 구성 비교에서도 후반 거리 분포와 태그 외 차이가 없었다. 이는 비교 전 상태의 강한 확인이지만 모든 운영 상태의 bitwise동일성 또는 통계적 유의성 주장은 아니다.

안정화 미달 episode는 seed0/1/2에서64/46/20개다. 이들 모두 최종행에서 `final_all_feet_in_radius=false`였고, 접촉·지지이력·수직속도·각속도 기준은 충족했다. 이는 종료 시점 관찰이지 전체 구간의 원인 확정이 아니다. 최초접촉은 모두 정밀했으므로 이후의 목표 유지 문제를 분리해서 조사할 근거가 된다.

다음 작업은 저장된200Hz trace에서 최초 발 접촉 이후의 발별 목표오차, 지지 중 발 중심 이동, 반경 이탈 시점과 최대 연속 목표유지 구간을 비교하는 것이다. 접촉 중 발 중심 이동을 마찰 미끄러짐으로 바로 단정하지 않는다. P2-20과 P2-21의 같은 scenario를 대조하고, 정확한 안정화 판정 재현에 필요한 샘플·hysteresis 정보가 부족하면 한계를 명시한다. 추가 거리 상한 sweep이나 중간checkpoint 반복 대신 이 실패구간을 먼저 분석한다.
