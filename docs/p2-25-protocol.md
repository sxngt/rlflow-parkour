# P2-25 거리 상한과 후반 탐색 상한의 조합

P2-21의20cm 학습분포는 일부15cm 도약에 성공했으나 안정화가퇴화했고, P2-24의후반std0.05는안정화가개선됐지만거리부족과seed별회귀가남았다. 두변경의결합을검증한다. 기존결과를확인한후추가한탐색적2×2비교이며독립확증실험이나효과의가산성을주장하지않는다.

|---|---:|---:|---|
| P2-20 | 15cm | 0.10 | 기존4seed재사용 |
| P2-21 | 20cm | 0.10 | 기존4seed재사용 |
| P2-24 | 15cm | 0.05 | 기존4seed재사용 |

P2-24에서 update801–1600 목표범위만[0,0.15]→[0,0.20]m로변경한다. 초기목표범위·보상·로봇·초기상태·출발반경·PPO·탐색초기일정은유지한다. P2-21대비로는1201–1600 std상한만0.1→0.05이다. 최악발보상을도입하지않는다.

fresh seed0–3,각1024환경×24step×1600update=39,321,600step, 추가157,286,400step. 고정평가0/5/10/15cm 각16개 총64개mean episode를유지한다. 20cm평가성능을주장하지않는다. 15cm성공·거리충족·최초정밀·안정화와짧은거리회귀를같이보고한다. 네조건의seed별결과와상호작용을기술적으로분석하고,작은seed수로통계적유의성/보편적개선을단정하지않는다.

축소일정64env3update로거리20cm/cap0.05/reset 및최종평가·영상경로를검증한다. 실제주요run의801/1201전환을별도확인한다. 모든최종평가에200Hz진단·64개렌더링/camera4·상세제목result영상·phase:P2/step:p2-25-distance-noise-combination을남긴다. 종료후8artifact감사와configs/reports/p2-25.json의비교·높이·지지면·착지후유지보고서를생성한다.

이전조건의좋은seed만선별하지않는다. 예산연장·실패seed교체·성공판정완화없이결과를보존한다. 조합이불안정하면추가적인작은상한sweep을계속하기보다목표표현/정책계약과실패구간의구조적원인을재검토한다.
