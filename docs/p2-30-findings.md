# P2-30 이산 혼합 목표의 능력 회복 결과

P2-29 split 정책4개에서15cm전용과reset별균등0/15cm혼합을동일예산으로추가학습했다. 신규8run×800update×1024env×24step=157,286,400환경step. 부모/새정책을각평가군에서동일시나리오로대조했다. 부모4새평가+새모델24평가의기록과영상무결성을확인했다.

## 분리 발판의0cm /15cm

아래각수치분모는거리별32다. 부모모델도같은0/15cm×32높이명령으로새평가했다.

| seed | 부모0cm | 전용0cm | 혼합0cm | 세조건15cm |
|---|---:|---:|---:|---:|
| 0 | 32 | 0 | 29 | 32 |
| 1 | 2 | 0 | 0 | 32 |
| 2 | 0 | 0 | 0 | 32 |
| 3 | 0 | 0 | 31 | 32 |

혼합학습은동일추가예산전용군보다seed0/3에서유리했다. 다만seed0은부모32→29로완전유지가아니며,seed1/2는회복하지못했다. 따라서네seed에서보편적능력회복을달성했다고볼수없다. 별도의split15cm×64유지평가에서는모든부모/새모델이64/64였다.

## continuous 혼합 거리 회귀

각괄호는0/5/10/15cm성공수이며각분모16이다.

| seed | 부모 |15cm전용추가|0/15cm혼합추가|
|---|---|---|---|
|0|16/16/16/16|0/16/16/16|11/8/16/16|
|1|1/16/16/16|0/16/12/16|0/0/16/16|
|2|0/16/16/16|0/16/15/16|0/8/16/16|
|3|0/16/16/16|0/16/16/16|15/16/16/16|

혼합조건seed0~2에서5cm수행손실이남았다. split에서5cm는발판사이의갭목표이므로같은지형에그대로혼합할수없다. 지형과명령가용성을함께고려해야한다. 성공한모든episode는원시200Hz최초접촉에서기대지지면의발구투영포함판정도통과했다. 이는최초접촉기하진단이며지속접촉이나실기성공을뜻하지않는다.

## 실제목표노출과판단

목표별reset확률과환경step비율은별개다. `p2-30-primary-goal-exposure.json`에초기배정/rollout배정/실제step을분리했다. 예를들어mixedseed1의0cmreset비율은약49.8%,step비율은65.1%였다. 0cm를거의학습하지않았기때문에실패했다고설명할수는없지만이비율만으로물리적실패원인을확정하지않는다.

이번조건은champion으로승격하지않는다. 다음은실패단계진단과학습출발점검토다. 이미잃은능력을복구하는것과이전능력을보유한부모에서유지하는것을구분해후속비교를설계한다. 단순예산연장이나성공seed선별로결론을대체하지않는다. 연속점프/Planner단계는아직완료하지않았다.
