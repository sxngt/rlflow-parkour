# P1 · Step 02a — 발별 단독 이동 사전 프로토콜

2026-09-11. Step 02의 3발 지지 순차 과제가 후반 접촉에 도달하지 못해 발별 실행 능력을 분리한다. FL/FR/RL/RR마다 처음부터 별도 정책을 학습한다. 발별 1 seed(0)의 탐색적 화면이며 발 간 통계적 우열을 주장하지 않는다.

- 각 1024환경 × 24step × 800updates = 19,660,800step. 4개 합계 78,643,200step. GPU 한 장에 한 run.
- v3 A와 동일 PPO, 69차원 관측, 행동, 12초 episode, 4–7cm 전방/±1cm 측방 목표, 이벤트 시 다른 3발 지지, 3.5cm lift 확인, 2.5cm 착지 반경 유지. 추가 수직 속도 벌점은 0.
- v4는 지정 발 1회 착지 후 최종 안정화(stage 4)로 전이한다. 다른 세 발 목표는 초기 위치를 유지한다. 완료 접촉은 최대 1회, 최종 active-foot 관측도 지정 발을 유지한다.
- 안정화는 4발 접촉·모든 목표 반경 충족·수직 속도 ≤0.1m/s·각속도 ≤0.5rad/s·기준 높이 차 ≤4cm를 연속 0.2초 충족한다. 1회 접촉만으로 성공하지 않는다.
- 마지막 checkpoint를 동일 개발군 생성 seed 10000의 64 episode로 평가한다. 각 발에 대응하는 목표 열을 사용하므로 발 간 목표 표본은 분포가 같으나 수치가 완전히 동일하지 않다.
- 성공/낙상/timeout, 착지 완료 수, 200Hz 접촉·몸체 진단, 종료 단계·phase를 보고한다. 16대 고정 격자 평가 MP4를 result에 보존한다.
- 실행 중 보상·예산 변경 없음. 성공률을 본 후 시험군 튜닝 금지. 본 개발군 결과는 최종 시험 결과가 아니다.
- 합성 상태 전이 검사와 단위 검사는 정책 학습 예산과 별도 기록한다. 모두 실패하면 학습 신호/실행 제약을 검토하고, 일부 성공하면 추가 seed 확인 후 순차 연결을 검토한다. 자동 champion 승격 없음.
