# P2-33: 준비 구간 명령 유지로 이동은 줄었지만 완주 개선 없음

동결된 P2-31 정책 4개에 동일한 개발 시나리오 64개씩을 적용했다. 두 번째 도약의 준비 구간만 기본자세 PD에서 첫 착지 성공 시 마지막 실행 관절 명령 유지로 바꿨다. 신규 학습은 0 step이다.

| seed | 기본 준비 완주 | 명령 유지 완주 | 준비 구간 평균 몸체 이동: 기본 → 유지 |
|---|---:|---:|---:|
| 0 | 0/64 | 0/64 | 7.43 → 0.21cm |
| 1 | 1/64 | 0/64 | 4.33 → 0.52cm |
| 2 | 0/64 | 0/64 | 4.06 → 1.62cm |
| 3 | 0/64 | 0/64 | 두 번째 시도 없음 |

모든 seed에서 첫 도약 이벤트의 모든 기록이 기존 대조와 동일했다. 200Hz 실행 action을 검사하여 준비 구간에 직전 action이 정확히 유지되었음을 확인했다. 시나리오·checkpoint hash·지형·학습 설정 동일성, 전환 상태 보존 및 원시 trace 대조도 통과했다. 결과는 `docs/p2-33-comparison.json`, 재계산은 `scripts/p2_33_report.py`에 있다.

준비 구간 몸체 이동 감소를 두 도약 성능 개선으로 해석할 수 없다. 기본자세로 복귀하는 준비 동작은 몸체 이동에 영향을 주지만, 그 이동을 줄이는 것만으로 다음 이륙과 착지를 해결하지 못했다. 이 실험의 처리 효과는 준비 구간 명령 및 그 결과로 달라지는 관측·접촉 상태를 포함하며 물리적 미끄러짐 원인 규명의 증거는 아니다.

4개 최종 영상의 hash·64개 렌더링·camera side 4·상세 제목을 확인했다(`artifacts/p2-33-videos-audit.json`). 전체 영상 육안 검수는 아직 하지 않았다.

후속은 임의 준비 명령 탐색을 반복하기보다 실제 착지 상태를 포함하는 고정 예산 학습 대조를 설계한다. 상태 수집·정상성 검사·초기화 계약과 기존 단일 도약 회귀 평가가 필요하다. 현 정책의 챔피언 승격 근거는 없다.
